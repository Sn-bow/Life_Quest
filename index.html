개인정보처리방침 / Privacy Policy

최종 업데이트: 2026-09-14 · 운영자: Log_Ian

현재 2.0 기기 모드: 가입 없이 사용합니다. 목표·퀘스트·진행 기록은 기기에 저장합니다. 광고, 결제, 클라우드 계정·동기화·신고 전송은 현재 테스트 빌드에서 제공하지 않습니다. AI는 선택 설치하며, 설치하지 않아도 기본 퀘스트를 사용할 수 있습니다.

1. 기기에 저장하는 정보

표시 이름, 시간·에너지·성장 분야·직접 입력한 목표, 퀘스트와 완료·피드백 이력, 레벨·능력치·인벤토리·던전·이야기 선택, 언어·소리·알림 설정을 앱의 기기 저장 공간에 보관합니다. 개인화 추천에는 최근 최대 90일 범위의 피드백 이력을 사용합니다. 홈 위젯을 사용하면 표시할 진행 정보가 위젯 저장 공간에도 남습니다.

이 정보는 앱 기능과 개인화 추천에 사용합니다. 기본 기기 모드에서 개발자에게 전송하지 않으며, 사용자 기록으로 모델 가중치를 학습시키지 않습니다. 현재 자동 클라우드 백업이나 기기 간 복원은 제공하지 않습니다. 앱 데이터 삭제·앱 제거·기기 분실 시 진행을 잃을 수 있습니다.

2. 온디바이스 AI와 모델 다운로드

선택한 Gemma 4 E2B 공개 모델은 지원되는 Android 기기에서 실행합니다. 모델 설치에는 약 2.59GB 다운로드와 저장 공간이 필요합니다. 모델 사용료와 클라우드 AI 호출료는 없지만 통신사 데이터 요금은 발생할 수 있습니다. 설치 후 퀘스트 생성은 인터넷 없이 기기에서 처리합니다.

사용자가 설치를 선택하면 공개 모델 파일을 Hugging Face 및 파일 전달 서버에서 내려받습니다. 이 서버에는 IP 주소와 파일 요청 같은 통신 정보가 전달됩니다. 목표·완료 기록·AI 입력 문구는 모델 다운로드 서버에 보내지 않습니다. 다운로드 서버의 정보 처리는 Hugging Face 개인정보처리방침을 참고해 주세요.

모델은 기기의 앱 전용 저장 공간에 보관하며, 설치 화면에서 다운로드를 취소하거나 재개하고 모델을 삭제할 수 있습니다. 프로필 삭제와 모델 파일 삭제는 별도이며, 앱을 제거하면 앱 전용 모델도 제거됩니다.

3. 권한과 자동 수집

인터넷 권한은 선택한 모델 다운로드와 사용자가 연 외부 페이지 등에 필요합니다. 알림은 사용자가 켠 경우에만 기기에서 예약합니다. Health Connect, Google Fit, 위치, 연락처, 캘린더, SMS, 마이크, 카메라의 사용자 데이터를 읽지 않습니다. 게임의 ‘건강’ 능력치는 게임 분류이며 실제 건강 측정값이 아닙니다.

현재 2.0 기본 Android 릴리스 구성에서는 AdMob, Google Play Billing, Firebase Analytics 및 Crashlytics 수집이 비활성화되어 있습니다. 자동 광고 식별자·분석·오류 보고 전송을 하지 않습니다. 이 공개 웹페이지도 분석 스크립트·추적 쿠키·외부 글꼴을 사용하지 않습니다. 호스팅 제공자 GitHub는 페이지 제공을 위한 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침

4. 계정·신고·결제 기능이 제공되는 버전

이 기능들은 현재 2.0 테스트에서는 제공하지 않습니다. 활성화하는 버전에서는 선택 전에 처리 범위를 안내하고 본 방침과 Google Play 데이터 보안 정보를 갱신합니다.

  • 클라우드 계정: Firebase Authentication의 이메일·사용자 ID, 사용자가 선택한 Google 계정의 기본 프로필 정보, 명시적으로 동기화를 선택한 앱 진행 데이터와 선택적 프로필 사진을 인증·복원에 사용할 수 있습니다. 기기 프로필을 자동 업로드하지 않습니다.
  • AI 문구 신고: 전송 직전에 사용자가 확인한 퀘스트 제목·안내·이유와 모델·언어 정보, 접수 시각 및 신고를 연결할 계정 식별자를 개발자에게 전달합니다. 기기 모드에서는 이메일 없는 임시 식별자를 사용할 수 있습니다. 전체 목표와 전체 이력은 자동으로 첨부하지 않습니다. 다만 선택한 문구 자체에 개인정보가 포함될 수 있으므로 전송 전에 확인해야 합니다.
  • 구매: 상품 ID, Google Play 구매 토큰 및 검증 결과, 계정과 연결된 이용 권한을 구매 확인·복원·환불 반영에 사용합니다. 결제 수단 정보는 Google Play에서 처리하며 개발자가 카드 번호를 받지 않습니다.
  • 보안: Firebase App Check 등 Google 서비스가 앱 무결성 신호와 연결 정보를 처리할 수 있습니다. Firebase Privacy and Security

계정 기능을 이용한 기존 버전의 사용자도 아래 삭제·문의 경로를 이용할 수 있습니다. 개인정보를 판매하거나 광고 타기팅을 위해 사용자 목표·퀘스트 기록을 제공하지 않습니다.

5. 보관과 삭제

기기 데이터는 앱 설정의 기기 기록 삭제, Android의 앱 데이터 삭제 또는 앱 제거로 지울 수 있습니다. 개발자는 기기에만 저장된 기록을 원격으로 조회하거나 지울 수 없습니다.

계정 기능이 제공된 버전의 계정·클라우드 진행·이미지·신고·앱의 구매 연결 기록은 계정 삭제 시 함께 삭제합니다. 삭제 처리 중에는 접근을 차단하고 실패한 서버 작업은 재시도합니다. 완료 후 내용 없는 삭제 처리 표식은 7일이 지나면 자동 삭제 대상으로 지정하며, 실제 제거까지 서비스의 처리 지연이 있을 수 있습니다. Google이 별도로 보관하는 결제·보안 기록은 해당 서비스 방침에 따릅니다. 계정 삭제가 구매 취소나 환불을 뜻하지는 않습니다.

이메일 문의로 보내는 주소·내용은 본인 확인과 요청 처리에만 사용합니다. 문의 종료 후 불필요한 내용은 삭제하며, 법적 보관 의무가 있는 경우 적용 근거와 기간을 안내합니다. 비밀번호, 인증번호 또는 카드 정보를 보내지 마세요.

6. 이용자 권리와 변경 안내

정보 열람·정정·삭제는 아래 문의 주소로 요청할 수 있습니다. 계정 관련 요청은 필요한 범위에서 본인 확인 후 처리합니다. Life Quest는 만 14세 미만 아동을 대상으로 하지 않으며 해당 아동의 정보를 의도적으로 수집하지 않습니다. 처리 방식이 바뀌면 이 페이지와 필요한 앱 안내를 갱신합니다.
