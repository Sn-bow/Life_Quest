# Life Quest Rebirth — 2026-09-20

## 제품 약속
**현실의 작은 행동으로 여러 세계의 나만의 성장기를 이어 쓰는, 기기 안의 상태창.**

Life Quest: 경계의 서가. 사용자는 ‘기록자’이며 도시 미스터리·무협 수련·기록 탐사 중 오늘 이어 읽을 책을 고른다. 완료한 현실 퀘스트가 다음 장면을 연다. 책을 바꿔도 성장과 선택은 이어진다.

2026-09-20 콘셉트·레퍼런스·수익 구조의 기준은 [CONCEPT_AND_REVENUE.md](CONCEPT_AND_REVENUE.md)다. [실제 화면 검토](CONCEPT_UX_REVIEW.md)에서 확인한 개선을 적용했다. 이번 회차는 최대30%만 사용하고 잔여70%를 남긴다. 공유 계정 한도는 실제 도구로 확인한다.

## 코드 및 운영에서 확인한 사실
- 기준 커밋: bdc7801, Flutter/Provider/Firebase + Flame, Android com.lifequest.app.
- 7개 하단 탭, CharacterState 약 2,300줄, 일간/주간/레이드 퀘스트와 카드 던전 구현.
- 실제 매출/유지율 자료 없음. 시장 성공 및 매출은 검증되지 않은 가설.
- 현재 결제 기본 비활성. 서버 영수증 검증/토큰 소유권/권한 영속성/RTDN 환불/재시도 삭제는 구현·로컬 검증됨. 선택적 구매 계정 분리는 구현·로컬 검증됨. 운영 배포와 실제 Play 테스트는 남음.
- 과거 문서에 비밀값이 노출된 흔적 발견. 값을 복사하지 않으며 공개 문서에서 제거. 기존 서명 키를 이 문서의 값으로 사용하지 않음.
- graphify는 lib의 코드 95개를 구조 분석. 생성된 번역 코드의 중복 관계 및 self-loop가 포함되므로 관계 그래프는 탐색 보조로만 사용. 변경 판단은 실제 코드를 확인.
- Play Console Log_Ian → Life Quest 기존 초안 확인. 설정 9/11, 카테고리/연락처와 스토어 등록 미완료. 프로덕션 접근 없음. 12명/14일 비공개 테스트 필수, 현재 0명.

## 첫 출시 제품 범위
1. 오늘: 이름·레벨·XP, 선택한 책과 다음 장면까지의 행동 수, 체크인, 개인화 추천3개와 진행 퀘스트. 헌터 랭크를 기본 정체성으로 사용하지 않는다.
2. 퀘스트: 직접 추가/편집, 일간/장기 목표. 추천은 수락할 때만 실제 퀘스트가 됨.
3. 카드 탐험: 기존 카드 전투를 선택 기능으로 유지. 현실 행동 보정과 방 단위 저장. 습관 사용에 게임을 강요하지 않는다.
4. 성장: 스탯, 기록, 업적, 장비/스킬/상점 진입. 기본 탭에서 상세 기능을 분리.
5. 이야기: 도시 「0번 출구」, 무협 「바람을 듣는 마당」, 탐사 「잃어버린 별의 지도」. 무료4장면×3권,4언어. 0/1/3/6개 현실 퀘스트로 해금하며 읽기·재선택은 XP를 주지 않는다.
6. 개인화: 기기 내 완료/보류/체감 난이도 기록, 시간 예산 및 관심 분야에 맞춰 다음 추천 조정. 모델 미지원 상태에서도 정상 작동.

## 온디바이스 설계 결정
- 사용자 추가 지시: 무료 공개 오픈모델을 먼저 조사하여 신중히 선정. Gemini Nano/AICore 종속 설계는 폐기. Qwen3.5 0.8B/2B, Gemma 4 E2B, LFM2.5 1.2B의 배포 조건/한국어/성능/크기를 비교하고 실측 후 결정.
- 클라우드 LLM 호출 없음. 원격 모델로의 조용한 전환 없음. AI 상태를 사실대로 표시.
- 초기 추천 엔진은 검증된 행동 후보로 작동. 오픈모델의 실제 생성 결과를 별도 평가하여 출력 검증/거부/기본 추천 경로를 갖춘 생성 시스템으로 확장. 모델이 보상, 결제, 삭제를 결정하지 않음.
- 기기 내 학습은 완료율/최근 반복/체감 난이도로 조정하는 추천 통계이며 LLM 가중치 학습을 주장하지 않음.
- 개인화 프로필과 세부 학습 기록은 기기 내 보관. 동기화되는 기존 퀘스트 제목/완료 데이터와 구분하여 개인정보 설명.
- 위험한 건강 처방, 극단 운동/식사, 돈 지출, 수면 제한 퀘스트 제외. 사용자가 건너뛰거나 초기화 가능.

## 수익 가설: 완결 세계관 팩
무료: 기본 퀘스트·개인화·온디바이스 AI·기록·세 단편·암호화 백업·카드 탐험.

판매 단위: 완결된 독립 이야기12장면·선택에 반응하는 두 결말·테마1종·능력치 없는 표식. 처음2장면 체험 후 Play의 실제 현지 가격으로 한 번 구매하는 구조. 첫 가격 검증 후보는6,900원이며 확정·등록·판매된 가격이 아니다. 기존4,900/2,900/9,900원 가설을 대체한다.

현재 무료 단편을 유료 팩으로 포장하지 않는다. 첫 팩 「조수 우체국」의12장면×4언어와 두 결말·테마·표식·2장면 체험·client/server SKU를 구현했다. 독자/번역 검수와 Play 상품 등록·실제 구매·환불·복원 검증은 남아 있다. 단독 테마 SKU는 기존 코드에 남아 있으나 출시 판매 대상에서 제외한다. 광고·AI 호출료·스탯 판매·실패 복구 결제·미완성 시즌 선판매는 하지 않는다.

제작비·전환율·수익은 검증되지 않았다. 무료 단편의 행동 유도와7일 복귀를 먼저 확인하고,12명 베타의 의견을 모집단 전환율로 일반화하지 않는다. 상세 비용 가정·Google2026지역별 수수료 변경 근거는 콘셉트 문서에 있다.
