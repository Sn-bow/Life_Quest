# Life Quest Rebirth — 2026-09-14

## 제품 약속
현실의 작은 행동을 나의 성장으로 바꾸는 개인 퀘스트 시스템. 하루 3개의 실행 가능한 추천, 명확한 상태창, 짧은 선택형 던전으로 다시 돌아올 이유를 만든다.

사용자 승인: 기존 디자인/기능/기획 전면 변경과 Google Play 배포를 위임받음. 디자인은 조사한 실제 레퍼런스에서 출발. 사용자 후속 지시에 따라 계정 잔량 5% 근처에서 작업 상태를 보존해 재개 가능하게 할 것. 계정 잔량은 공유 한도여서 시간/토큰으로 정확히 환산하지 않는다.

## 코드 및 운영에서 확인한 사실
- 기준 커밋: bdc7801, Flutter/Provider/Firebase + Flame, Android com.lifequest.app.
- 7개 하단 탭, CharacterState 약 2,300줄, 일간/주간/레이드 퀘스트와 카드 던전 구현.
- 실제 매출/유지율 자료 없음. 시장 성공 및 매출은 검증되지 않은 가설.
- 현재 결제 기본 비활성. 서버 영수증 검증/토큰 소유권/권한 영속성/RTDN 환불/재시도 삭제는 구현·로컬 검증됨. 운영 배포·구매 계정 연결·실제 Play 테스트는 남음.
- 과거 문서에 비밀값이 노출된 흔적 발견. 값을 복사하지 않으며 공개 문서에서 제거. 기존 서명 키를 이 문서의 값으로 사용하지 않음.
- graphify는 lib의 코드 95개를 구조 분석. 생성된 번역 코드의 중복 관계 및 self-loop가 포함되므로 관계 그래프는 탐색 보조로만 사용. 변경 판단은 실제 코드를 확인.
- Play Console Log_Ian → Life Quest 기존 초안 확인. 설정 9/11, 카테고리/연락처와 스토어 등록 미완료. 프로덕션 접근 없음. 12명/14일 비공개 테스트 필수, 현재 0명.

## 첫 출시 제품 범위
1. 오늘: 레벨/랭크, 오늘의 진척, 체크인, 개인화 추천 3개와 현재 진행 퀘스트.
2. 퀘스트: 직접 추가/편집, 일간/장기 목표. 추천은 수락할 때만 실제 퀘스트가 됨.
3. 던전: 기존 Soul Deck 전투 재사용. 현실 행동 보정과 짧은 선택형 플레이.
4. 성장: 스탯, 기록, 업적, 장비/스킬/상점 진입. 기본 탭에서 상세 기능을 분리.
5. 개인화: 기기 내 완료/보류/체감 난이도 기록, 시간 예산 및 관심 분야에 맞춰 다음 추천 조정. 모델 미지원 상태에서도 정상 작동.

## 온디바이스 설계 결정
- 사용자 추가 지시: 무료 공개 오픈모델을 먼저 조사하여 신중히 선정. Gemini Nano/AICore 종속 설계는 폐기. Qwen3.5 0.8B/2B, Gemma 4 E2B, LFM2.5 1.2B의 배포 조건/한국어/성능/크기를 비교하고 실측 후 결정.
- 클라우드 LLM 호출 없음. 원격 모델로의 조용한 전환 없음. AI 상태를 사실대로 표시.
- 초기 추천 엔진은 검증된 행동 후보로 작동. 오픈모델의 실제 생성 결과를 별도 평가하여 출력 검증/거부/기본 추천 경로를 갖춘 생성 시스템으로 확장. 모델이 보상, 결제, 삭제를 결정하지 않음.
- 기기 내 학습은 완료율/최근 반복/체감 난이도로 조정하는 추천 통계이며 LLM 가중치 학습을 주장하지 않음.
- 개인화 프로필과 세부 학습 기록은 기기 내 보관. 동기화되는 기존 퀘스트 제목/완료 데이터와 구분하여 개인정보 설명.
- 위험한 건강 처방, 극단 운동/식사, 돈 지출, 수면 제한 퀘스트 제외. 사용자가 건너뛰거나 초기화 가능.

## 수익 가설: 소장하는 성장 챕터
무료: 기본 개인화, 무제한 수동 퀘스트, 진행 기록, 무료 프롤로그, 암호화 백업, 첫 던전.
유료 실험: 완결형 스토리 챕터 + 상태창 테마 + 스토리 칭호를 영구 소장. 구매 후 기간 만료 없음. 실제 챕터가 완성되고 Google Play 상품이 확인되기 전에는 구매 버튼을 노출하지 않음.
가격 실험안(확정 가격 아님): 챕터 4,900원, 테마 모음 2,900원, 첫 완결 챕터 묶음 9,900원. 사용량 기반 AI 과금 없음. 랜덤 유료 뽑기/능력치 판매/실패 시 결제 유도 없음.
차별점은 새로운 과금 방식 자체가 아니라 생활 목표와 함께 진행되는 완결형 콘텐츠. 제작비와 전환율 검증 필요.
초기 검증: 첫 퀘스트 수락/완료, D1/D7 복귀, 추천 수락·보류, 던전→다음 현실 행동, 구매 화면 도달/전환. 개인별 퀘스트 원문 수집 금지. 초기 테스트에서는 동의 받은 익명 피드백으로 검증.
