# 台灣繁體中文文案 QA — 2026-09-28

## 범위

- 기존 `app_zh.arb` 1,473개 번역 키와 네 편의 `*_zh.json` 이야기는 OpenCC `s2twp` 자동 변환본을 기반으로 검토했다. 이후 구매 계정 연결 문구 3개 키가 추가되어 현재는 1,476개다. `zh`는 앱에서 번체 중국어(대만)로 안내한다.
- 이후 사람의 문맥 판단으로 핵심 앱 용어를 정리했다. `狀態視窗`(상태창), `任務`(퀘스트), `帳號`(계정), `設定`(설정), `儲存`(저장)을 사용한다. 구매 복원은 `還原購買`, 체력 회복은 `恢復 HP`로 구분했다.
- 첫 화면의 상태창, 퀘스트 기본 템플릿 16개, 알림 문구 4개, 계정 삭제·구매 복원·백업 안내, 스토리의 대만식 어휘와 잘못 변환된 단어를 수정했다. 특히 계정 삭제 버튼이 로그아웃처럼 보이던 문구를 `刪除帳號`로 바로잡았다.

## 확인

- `app_zh.arb`와 영어 ARB의 번역 키가 각각 1,476개로 일치한다. JSON 파싱에 성공했다.
- 네 편의 중국어 스토리 JSON 파싱에 성공했고, 각 장면·선택지·분기 ID가 영어 원본과 일치한다. 장면 수는 4/4/4/12개다.
- `zh` 퀘스트 기본 템플릿과 알림에서 발견된 간체 문구를 번체로 바꿨다. `狀態窗`과 `我的狀態列`은 같은 개념을 가리키는 `狀態視窗`으로 통일했다.

## 남은 검증 범위

- 이번 검토는 전문 대만 원어민 감수나 현지 사용자 사용성 시험을 대체하지 않는다. 특히 서사 전체의 문체·인명 표기는 출판 수준의 현지 편집을 받지 않았다.
- 온디바이스 AI 생성 문구는 프롬프트가 대만 번체를 요구하지만, 생성물 자체를 번체로 변환하거나 글자별로 검증하지 않는다. 실제 대만 기기에서 생성 결과를 확인해야 한다.
- Flutter `gen-l10n`, 전체 테스트와 AAB 빌드는 루트 작업과 충돌하지 않도록 루트 에이전트가 직렬 실행한다. 이 문서는 그 실행을 완료했다고 주장하지 않는다.
