# 판매 가치와 구현 결정 · 2026-10-03

## 목표와 판단의 한계
실제로 사용할 이유와 비용을 지불할 이유를 갖춘 앱을 완성하고 검증한 뒤 비공개 테스트에 배포한다. 내부 QA, 비교 앱 다운로드, 유료 테스터의 설치를 Life Quest의 구매 수요로 보고하지 않는다. 실제 순매출은 출시 이후 관측할 수 있으므로 제품 품질 판정과 매출 실적을 구분한다. 이번 결정은 실행할 제품 전략이며 흑자 보증이 아니다.

## 구현할 제품
Life Quest의 상태창은 실제 행동 결과를 보여주는 진입점으로 유지한다. `무엇을 할지 매번 작성해야 하는 RPG 할 일 목록`의 부담을 줄인다. 핵심은 **목표 선택 → 구체적인 미션 → 실행/짧은 버전 선택 → 결과 기록 → 다음 단계**다. 달력 연속출석이나 가짜 전투가 진도를 결정하지 않는다.

- 학습, 정리, 가벼운 움직임, 관계의 네 루트. 루트당 21개의 서로 다른 미션, 3개 장(시작/방법 찾기/유지). 각 미션은 명확한 완료 조건과 별도로 작성한 작은 행동 버전을 제공한다. 짧은 버전도 고르기만 하고 끝나지 않도록 실제 행동을 포함한다.
- 첫 7개 미션은 각 루트 무료. 기본 직접 퀘스트, 일일 추천, 기존 기록/백업은 무료로 유지한다. 무료 사용자도 완결된 첫 장을 사용할 수 있다.
- 일회 구매 `Life Quest Complete`: 각 루트 8–21 미션, 결과/회고를 보존하는 전체 루트, 기존 상태창 외관·상세 분석/저장. 구매 전에 실제 목차와 미션 예시를 확인한다. XP 배율이나 실패 벌금 판매 없음.
- 가격 가설: 미국 $4.99 상당의 일회 구매. 실제 표시/통화는 Google Play 상품 응답만 사용. 정기결제나 장래의 무제한 신상품 제공을 약속하지 않는다.
- 쉬운 날/휴식 후에도 진도 보존. 짧은 버전으로도 동일한 단계 완료 가능. 신체 활동은 무리 없는 선택형이며 치료/운동 처방을 주장하지 않는다.
- 목표와 완료 기록은 기기에 저장. 선택형 기존 온디바이스 AI는 무료 추천 보조로만 유지; 큰 모델 다운로드 없이 핵심 제품을 끝까지 사용한다.

## 완료 확인 기준
1. 84개 미션 전부 4개 언어로 제공하고 첫 장/끝 장/완료 후 사용이 연결될 것.
2. 실제 완료만 진도/XP 반영, 중복 탭/재시작/백업/계정 전환에 기록 보존, 취소와 환불에 구매 권한 일치.
3. 휴대폰 작은 화면·태블릿·큰 글꼴·일본어/번체에서 핵심 흐름 점검.
4. 구매 전 가치 확인 → Play 결제 → 검증 → 권한 → 복원/환불의 실제 경로가 마련될 것. 단순 SKU 생성은 완료 아님.
5. 출시 문구, 개인정보, 가격·지원·테스트 안내가 실제 동작과 일치할 것.
6. 경쟁 대안 대비 이점/약점과 운영비를 최종 재평가하고, 중대한 미완성은 배포로 덮지 않을 것.
