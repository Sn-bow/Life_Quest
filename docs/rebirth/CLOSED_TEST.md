# Google Play 비공개 테스트 등록 · 2026-09-21

**현재 상태: Alpha 트랙 설정과 릴리스 초안 저장. AAB 업로드·심사 제출·테스터 배포는 미완료.** 등록 완료나 14일 참여 기간 시작으로 보고하지 않는다.

최신 사용자 요청은 비공개 테스트를 먼저 등록하는 것이다. 실제12명 이상의 모집·크몽 등의 비용 지출은 사용자가 직접 진행하겠다고 했다. 대신 결제하거나 모집 메시지를 보내지 않았다.

## 실제 저장된 설정

- 기존 `Alpha` 트랙을 사용했다. 새 트랙을 중복 생성하지 않았다.
- [트랙 관리](https://play.google.com/console/u/1/developers/8167226228602257815/app/4972166589004992203/tracks/4698525131707810433)
- 국가: 대한민국. 프로덕션 국가와 동기화 해제, 추가 변경사항이 게시 개요에 저장됨을 확인했다.
- 전용 이메일 목록: `Life Quest 2.0 Closed Test`. 준비용 개발자 본인 계정1개만 추가했다. 기존 다른 앱/품앗이/친구 목록은 연결하거나 변경하지 않았다. 목록1명은 실제 테스터 참여1명이라는 뜻이 아니다.
- 의견 주소: https://sn-bow.github.io/Life_Quest/#contact
- 트랙 설정 완료 표시는 **2/4**, 트랙은 **비활성**이었다.
- [비공개 릴리스1 초안](https://play.google.com/console/u/1/developers/8167226228602257815/app/4972166589004992203/tracks/4698525131707810433/releases/1/prepare)
- 출시명: `2.0.0 (7) · 경계의 서가 · 비공개 테스트`.
- EN/KR 노트를 입력하고 저장 성공을 확인했지만, 새로 열자 **영어만 유지**됐다. 한국어가 영구 저장됐다고 보고하지 않는다. 한국어 등록정보/언어가 실제 저장돼 있는지 후속 확인한다.
- 참여 탭은 ‘앱을 게시하면 링크가 여기에 표시됩니다’ 상태다. 유효한 테스터 참여 링크는 아직 확인하지 못했다. 패키지명으로 URL을 추측해 작동하는 링크로 제공하지 않는다.

## 현재 막힌 단계

1. 이전 세션의 `fileChooser.setFiles: Not allowed` 이후, Chrome ChatGPT 확장의 ‘파일 URL에 대한 액세스 허용’을 켜달라고 사용자에게 요청했고 답변을 기다린다. 이 세션에서는 업로드 버튼/파일 선택 이벤트까지 열었지만 파일을 전달하지 않았다. 확장 설정 페이지를 읽으려던 접근은 브라우저 URL 보안 정책에 의해 차단됐다. 그 설정 화면을 다른 표면으로 우회하지 않는다. 기본 파일 선택기 대안을 확인했지만 네이티브 Chrome에는 선택 대화상자가 나타나지 않았다.
2. Play 앱 콘텐츠 화면이 반복해서 오류를 냈다. 일반 진입 `788160E3`, 새로고침 후 `5C1729B4`. 릴리스 ‘다음’도 `6CB3EADC`로 미리보기 내용이 나오지 않았다. 오류를 무시하고 심사 제출하지 않았다.
3. 게시 개요에는 예전 ‘전체 또는 일부 기능이 제한됨’ 앱 접근 안내가 남아 있다. 현재 가입 없는 빌드와 일치하도록 앱 콘텐츠 화면이 복구되면 확인/수정해야 한다. 이전 콘텐츠 등급/건강/데이터 보안 선언도 이번 빌드 기준으로 검토해야 한다. 현재 선언의 완료 표시를 최신 빌드의 적합성 근거로 삼지 않는다.
4. 기존 Play용 아이콘/배너는 준비돼 있지만 최종 스토어 그래픽·등록정보 검증은 남아 있다. AI 신고는 수동 복사·외부 문의 경로이므로 Play 제출용 인앱 신고 운영 요건도 별도로 검토해야 한다.

이전414개 코드 테스트 결과가 테스터 참여로 인정되는 것은 아니다. 자체 공개 APK 설치도 비공개 테스트 참여로 집계하지 않는다. 실제 테스터 이메일을 받은 뒤 이 전용 목록에 추가하고, Google 검토/배포 완료 후 실제 참여 링크를 전달해야 한다.
