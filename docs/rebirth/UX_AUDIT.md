# 첫 실행 흐름 감사 — 2026-09-14 KST

관찰 대상: bdc7801의 기존 UI, Flutter 3.47 아이콘 호환 수정 후 QA preview. 412 × 892 브라우저 화면. Android 실기기 감사와 구별한다. `qa_artifacts/rebirth/before-today.png`, `reference-lifeup.png`, `reference-arise-gallery.png`에 원본 화면 저장.

1. 첫 화면의 390px가 설명형 요약 패널이다. 실제 퀘스트 완료 버튼이 첫 viewport에 없다. 오늘의 3개 행동을 먼저 노출한다.
2. 하단 7개 목적지는 좁고 텍스트가 작다. 오늘/퀘스트/던전/성장 4개로 묶고 장비·스킬·상점·업적은 성장에 배치한다.
3. 완료 0개 상태에서도 첫 턴 드로우, 마법 카드, 악마의 도박 같은 용어가 나온다. 행동 전에는 시간·구체적인 할 일·보상을 설명한다. 게임 용어는 던전에서 안내한다.
4. 퀘스트 목록에도 동일한 큰 설명 패널이 반복된다. 목록의 첫 화면에서 바로 체크할 수 있게 줄인다.
5. 모든 패널에 비슷한 색·굵기·둥근 테두리를 사용해 시선의 우선순위가 불분명하다. 강한 상태 요약 하나와 간결한 행동 행을 사용한다.
6. 다음날 미완료로 HP·레벨·XP를 잃는 코드가 있다. 쉬고 돌아온 사용자가 누적 성장을 잃지 않게 변경하고 회복용 작은 행동을 제안한다.

참고 적용: LifeUp Play 실제 목록의 한 행/한 행동과 완료 컨트롤, Finch의 작은 행동 및 부드러운 복귀 유도, ARISE 공식 갤러리의 짙은 배경과 보라·청록 대비, Material의 3~5개 핵심 내비게이션. 웹툰 캐릭터/로고/갤러리 이미지 자체를 제품에 복사하지 않는다.

기능 판단은 이 앱의 실제 화면/코드에 기반하며 외부 제품의 리텐션 효과를 실증한 것으로 보지 않는다.
