# 실제 Android 확인 안내

대상은 `com.lifequest.app`2.0.0+4의 **main** 릴리스다. 파일: `build/app/outputs/flutter-apk/app-release.apk`(ARM64,약186MB). 공개 출시 전 개발 검증용이며, Cloud·결제·광고·AI 신고 전송은 꺼져 있다. APK 서명/정렬 검사와 실제 휴대전화 동작은 별개다.

1. 기종, Android 버전, RAM·여유 저장 공간을 기록한다. 개인 목표나 화면 속 개인정보를 제출할 필요는 없다.
2. 가입 없이 시작해 가용 시간·관심 분야를 고르고 첫 퀘스트를 수락/완료한다. 오늘 XP와 실제 완료 수를 확인한다.
3. 경계의 서가에서 수련 책을 선택하고 첫 장면에 응답한다. 실제 퀘스트1개를 완료하면 두 번째 장면이 열려야 한다. 책을 바꾸고 앱을 재시작해도 진행이 남아야 한다.
4. 시스템 글자 크기를 크게 하고 TalkBack으로 수락·완료·세계 선택·뒤로 이동을 확인한다. 설정의 알림을 거부해도 핵심 기능을 쓸 수 있어야 한다.
5. 모델 미설치 상태/비행기 모드에서도 기본 추천과 수동 퀘스트를 확인한다. 지원 기기에서만 선택 모델을 설치한다. 약2.59GB 다운로드와 여유 공간이 필요하므로 실제 설치는 사용자가 선택한다.
6. AI를 시험하면 생성 지연·발열·강제 종료 여부·한국어 자연스러움을 기록한다. 이상한 제안은 수락하지 않고 기본 추천으로 돌아갈 수 있어야 한다. 이번 빌드의 신고 전송은 작동하지 않으며, 공개 출시 전 서버 연결이 필요하다.
7. 임의의 테스트 비밀번호로 백업을 내보낸다. 같은/다른 기기에서 복원 전 요약, 복원 후 이야기 선택, 직전 기록 되돌리기를 확인한다. 실제 비밀번호나 원본 백업 파일을 공개 이슈에 올리지 않는다.
8. 카드 탐험 방에 진입하고 앱을 종료한다. 같은 방 입구에서 이어지고, 최종 보상을 다시 열어도 중복 XP가 없어야 한다.

실제로 실행한 항목만 pass/fail로 기록한다. 테스터가 확보되면 [Play 테스트 계획](store/STORE_AND_TEST_PLAN.md)의14일 절차로 이어간다. 이 문서는 완료 증거가 아니다.


이 APK는 업로드 키로 서명했다. Play가 별도 앱 서명 키를 사용하면 직접 설치본을 그대로 업데이트하지 못할 수 있다. 실제 기록을 쌓기 전 검토용으로 사용하고, Play 테스트 트랙으로 옮길 때 먼저 암호화 백업을 보관한다. 개별 APK 설치를 Play 비공개 테스트의 참여 기간 충족으로 계산하지 않는다.
