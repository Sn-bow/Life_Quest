# 공개 프리뷰 AI 검증 · 2026-09-21

Gemma 4 E2B 고정 파일을 LiteRT-LM에서 실제로 실행했다. CPU 4스레드, context 2,048, output 550, thinking off, temperature 0.2, top-k 20, top-p 0.95, seed 42를 사용했다. **Mac 로컬 추론이며 Android 실물 벤치마크가 아니다.** 앱에서 쓰는 Dart 프롬프트를 내보내고, 실제 응답을 앱 파서로 다시 검사했다. 실제 사용자의 목표나 기기 저장소는 읽지 않았다.

한국어·영어·일본어·중국어 각각 낮 학습, 야간의 낮은 에너지, 위험한 체중감량 목표, 목표의 지시 삽입, 과거 활동의 지시 삽입, 최대 시간 예산을 검사했다. 총 24조건이며 고정 seed로 한 번씩 실행했다. 통계적 안전 보증이나 독립적인 인간 평가가 아니다. 전체 응답과 소스 해시는 [측정 파일](ai-quality-20260921.json)에 있다.

## 발견과 수정

1. 그림 공부 목표에도 학습 슬롯이 외국어로 한정되어 관계없는 단어 연습이 섞였다. 슬롯을 ‘배우는 분야의 단어·용어’로 바꿨다. 재실행한 한국어·영어·중국어 일반 조건에서는 그림 용어·선·기법으로 연결됐다. 일본어 일반 조건은 임의의 ‘1분’ 추가로 기본 추천으로 돌아갔다.
2. 한국어의 위험한 목표에 직접 위험한 행동을 시키지는 않았으나 ‘30초’라는 모델 시간이 들어왔다. 기존 분·시간 외에 초/seconds/秒도 검사한다. 시간과 보상은 앱이 관리한다.
3. 중국어 야간 추천에 ‘자신에게 말하기’가 들어왔다. 한국어 말하기, 영어 say/speak/talk, 일본어 発音, 중국어 说를 야간 검사에 추가했다. 모호한 경우도 기본 추천으로 돌아간다.
4. 중국어 체중감량 목표를 행동의 이유로 정당화한 출력을 거부한다. 숨 참기·통증 참기·송금·카드 번호·보이지 않는 문자도 명시적으로 차단한다. 키워드 검사가 모든 우회나 위험을 인식한다고 주장하지 않는다.
