# 본인 Android 휴대폰으로 확인하는 Play 결제 — 2017

2026-10-06. USB 연결 없이 사용하는 안내다. **2.2.0 (2017)를 14:22 KST 본인 내부 트랙에 게시**했고 Console의 ‘내부 테스터에게 제공됨’을 확인했다. 크몽의 비공개 테스트나 정식 판매를 뜻하지 않는다. [현재 체크포인트](../CONTINUE.md), [게시 기록](../play-owner-testing-2017.json).

- [휴대폰에서 테스트 참여](https://play.google.com/apps/internaltest/4701695828383701621)
- 휴대폰 앱 정보에서 확인할 버전: **2.2.0**, 패키지 `com.logian.lifequest`. **2017**은 Play Console의 내부 빌드 번호이며 일반 앱 정보에 함께 표시되지 않을 수 있다.
- Google 검토 전에는 `com.logian.lifequest (unreviewed)`라는 임시 이름이 보일 수 있다.
- 구매 상품: Life Quest Complete, `quest_journeys_complete_01` / `complete-once`.
- 10월 6일 본인의 명시적 승인 후 서버 서비스 계정이 Play 사용자 목록에 **활성**으로 등록됐다. 단일 앱의 정보 읽기·재무/구매 API·주문 관리 권한이다. 구매 옵션도 6개국 **활성** 상태로 확인했다.
- 이후 본인의 테스트 구매·구매 복원 성공과 서버 Complete 활성 유지를 확인했다. 본인이 최종 환불을 직접 눌렀고 Play ‘환불됨’·RTDN 성공·서버 구매 revoked/권한 inactive까지 확인했다. 휴대폰에서도 다시 구매가 필요한 상태와 앱 정보2.2.0을 보고했다. [10/6 테스트 결과와 확인 범위](../qa/play-test-purchase-20261006.md). 기존 무료 기록 보존 결과는 아직 사용자 보고 전이다.
- 최신 지시: 앱 완성을 위한 내부 QA는 계속한다. 크몽 외부 테스터용 비공개 배포는 앱 완성과 준비 상태를 먼저 보고할 때까지 보류한다. 내부 테스트는 Google의 비공개 최소12명·연속14일 요건에 포함되지 않는다. [Google 공식 요구사항](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko).

## 먼저 할 일

1. 휴대폰 Google Play에서 지정한 판매자 본인 Google 계정을 선택한다. 참여 링크도 같은 계정으로 연다.
2. 본인 계정은10/6 참여 페이지에서 이미 테스터로 확인됐다. `Download test app`을 선택하고 표시되는 Google Play 링크로 설치하거나 업데이트한다. 다른 계정은 참여 안내를 읽고 본인이 테스트 참여를 먼저 해야 한다.
3. 휴대폰 설정의 앱 정보에서 버전이 **2.2.0**인지 확인한다. 내부 번호2017이 함께 보이지 않아도 된다. 앱 자체의 설정에는 버전 표시가 없다. 이전 버전이 보이면 새 버전이 Play에 반영된 뒤 업데이트한다. 다른 서명의 개발 APK 때문에 설치가 거절되면 기존 기록을 백업하고 원인을 확인한다. 진행 기록을 남긴 채 앱을 무작정 지우지 않는다.
4. Complete 화면을 열고 Google 계정을 연결한다. Play 구매창에서 **테스트 구매 안내와 테스트 카드**가 보이는지 먼저 확인한다. 이 시점에는 표시 여부만 알려줘도 된다. 일반 카드만 보이면 결제를 취소하고 설치/구매 계정을 점검한다.

## 승인 테스트와 그다음 확인

본인 게시 계정은 Google의 라이선스 테스터이며 테스트 결제 수단에는 실제 금액이 청구되지 않는다. 내부 테스트 참여만으로 일반 사용자의 결제가 무료가 되는 것은 아니다. [Google 안내](https://support.google.com/googleplay/android-developer/answer/6062777), [결제 테스트 문서](https://developer.android.com/google/play/billing/test).

1. Google 구매창의 **항상 승인하는 테스트 카드**를 선택해 테스트 구매한다. 일반 카드로 바꾸지 않는다.
2. 앱에 Complete 이용 권한이 적용되고 8번째 이후 미션에 접근할 수 있는지 확인한다. 구매한 시각과 앱의 성공/오류 문구만 알려준다. 서버에서는 실제 구매 검증과 승인 처리를 확인한다.
3. 앱을 종료했다가 다시 열고 구매 복원을 실행한다. 접근 권한과 무료 진행 기록이 함께 남는지 확인한다.
4. 서버 확인 후 해당 **테스트 주문만** 환불·권한 회수한다. 앱에서 온라인으로 다시 확인했을 때 유료 접근이 해제되고 기존 무료 기록·작성한 도구가 보존되는지 확인한다. 다른 주문을 환불하지 않는다.
5. 거절/보류 테스트는 첫 승인 테스트 결과를 확인한 다음 별도로 진행한다. 보류 중에는 유료 기능이 열리면 안 된다.

설치·오류 확인에는 휴대폰 기종, Android 버전, 앱 버전, 시간, 화면의 오류 문구가 도움이 된다. 비밀번호·카드 번호·구매 토큰·주문 번호를 공개 문서나 SNS에 남기지 않는다. 계정 삭제·앱 데이터 삭제는 이 기본 결제 절차에 포함하지 않는다.

테스트 카드 구매는 실제 매출이나 사용자 구매 수요가 아니다. 이 검사 결과를 앱 전체 완성 또는 수익 달성으로 대신하지 않는다.
