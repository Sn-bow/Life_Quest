# Play 초안과 첫 테스트 계획

이 문서는 준비 상태와 검증 순서를 설명한다. 공개 출시, 유료 상품 판매 또는 테스터 모집 완료를 의미하지 않는다.

## 등록 방향

주 기능은 습관·목표 관리이므로 앱 / 생산성으로 분류한다. 카드 던전과 이야기는 일상 행동에 돌아올 이유를 주는 기능이다. LifeUp의 작업 중심 표현을 참고하며, 다른 작품 이름이나 캐릭터를 검색어/아이콘/스크린샷으로 사용하지 않는다.

Console에서 앱/생산성 분류와 공개 지원 이메일·HTTPS 주소를 저장했다. 기본 영어 등록정보 및 한국어 번역의 이름/짧은 설명/상세 설명도 임시보관함에 저장한 결과를 확인했다. 필수 그래픽이 없어 등록 완료나 심사 가능 상태는 아니다.

한국어 문구는 `ko-KR.txt`의 앱 이름(20자), 짧은 설명(45자), 상세 설명(1,228자). 실제 제공 중인 무료 프롤로그·암호화 백업·선택형 공개 모델만 소개한다. 판매하지 않는 유료 챕터와 계정 연동을 완료 기능으로 쓰지 않는다. 설치 공간, 다운로드 통신요금, 비밀번호 복구 불가, 미완료 방을 입구에서 다시 시작하는 범위도 설명한다.

이미지 생성으로 새 아이콘·첫 화면·프롤로그 표지·feature graphic을 제작하고 앱에 적용했다. Play용 512px 아이콘과1024×500배너도 준비했다. `../artwork/README.md`에 제작 기록이 있다. `../screens/`는 CUA로 확인한 브라우저 구현 캡처이며, 스토어 최종 제출용 Android 캡처라고 주장하지 않는다. 실물 Android 스크린샷은 준비해야 한다.

기존 콘텐츠 선언이 9/11 완료 표시여도 2.0의 사실과 일치하는지 다시 검토한다. 특히 광고 없음, 계정 없는 기기 모드, 온디바이스 처리, 외부 모델 다운로드, 선택적 미래 결제/신고 전송은 실제 제출 빌드 기준으로 답한다. 출시 후 기능을 켤 때 개인정보/데이터 보안/앱 접근 안내도 함께 바꾼다.

## 사람을 대상으로 테스트하기 전

1. 실물 Android에서 신규 실행·앱 재시작·하루 경계·오프라인·알림 거부·큰 글자·접근성을 확인한다. 모델 미설치/미지원 기기에서도 첫 퀘스트 완료가 가능해야 한다.
2. 저장 공간이 부족한 설치, 네트워크 중단, 취소/재개, checksum 오류, 모델 삭제를 확인한다. 실제 모델 생성의 발열·메모리·지연·한국어 자연스러움을 기록한다. 에뮬레이터 측정을 실기기 성능으로 쓰지 않는다.
3. Android 파일 선택기에서 암호화 export/import/cancel을 확인한다. 잘못된 비밀번호/변조 파일은 원래 기록을 남겨야 한다. 새 기기에 가져오면 이름·퀘스트·이야기 선택이 일치하고 알림은 꺼져 있어야 한다.
4. AI 신고를 앱 안에서 실제 접수할 수 있게 백엔드와 삭제/보관 안내를 완성한다. 삭제된 Firebase 프로젝트 처리와 함수 운영 요금 문제는 사용자 답변이 필요하다.
5. 결제를 활성화할 빌드라면 기기 기록을 업로드하지 않는 Google 구매 계정 연결, 서버 권한, 복원·환불·계정 변경·탈퇴를 실제 Play 테스트 결제로 검증한다. 완성한 유료 콘텐츠만 상품 조회 목록에 넣는다.
6. APK/AAB 서명 및 16KiB 검사를 통과한 정확한 버전만 Play 내부 트랙에 올린다. 기존 업로드 인증서가 없으므로 첫 업로드 때 이번 공개 인증서 지문과 일치하는지 확인한다. 키의 비밀값을 Console/문서에 붙이지 않는다.

## 비공개 테스트

현재 계정은 12명 이상이 연속 14일 동안 참여 선택 상태를 유지해야 프로덕션 신청을 할 수 있다. 기준은 실제 [Play Console의 계정별 표시](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)를 따른다. 테스터는 실제 사용자여야 하며 가짜 계정이나 테스트 결과를 만들지 않는다. 사용자에게 실물 Android 기종과 테스터 확보 여부를 질문한 상태다. 아직 누구에게도 모집 메시지를 보내지 않았다.

- 시작 전: 검증된 내부 빌드에서 치명적 실패를 해결하고 설치 링크/버전/알려진 제약을 작성한다.
- 1일차: 가입 없이 3분 안에 첫 퀘스트를 수락·완료할 수 있는지 본다. 개인 목표 원문을 제출하게 하지 않는다.
- 2–4일차: 한 번 쉬었다가 복귀, 추천 보류/완료, 다른 여유 시간 선택. 반복되거나 어색한 추천은 사용자가 동의한 해당 출력만 신고하게 한다.
- 5–7일차: 카드 전투·갈림길·보상·스토리 두 번째 장면. 일상 행동으로 돌아오는 이유가 생기는지 짧게 묻는다.
- 8–14일차: 백업 이동·모델 미설치 상태·알림 거부·저장 실패 복구를 점검한다. 사용자가 앱을 계속 열 이유와 그만두는 이유를 기록한다.
- 종료 후: 실제 참여 기간/수, 주요 결함과 수정, 유지·이탈 피드백을 근거로 프로덕션 액세스를 신청한다. 기간 충족 자체가 승인 보장은 아니다.

## 수익 검증

무료 개인화와 백업을 유지하고, 완결형 이야기 + 테마 + 이야기 칭호를 한 번 사서 소장하는 상품을 실험한다. 초기 가격은 검증할 가설이며 Play 상품 설정·제작비·전환율 확인 전 확정하지 않는다. 구독이나 AI 호출 과금 없이 추가 콘텐츠를 고르는 이유가 있는지를 검증한다. 실제 매출/전환율 데이터는 아직 없다.

2026-09-17: 영문2,194자/한국어1,228자의 최신 상세 설명을 Console 임시보관함에 저장하고 성공 메시지를 확인했다. 아이콘·배너 파일은 준비했으나 Chrome 확장 파일 URL 권한 미허용으로 업로드 대기다. Android 실물 스크린샷과 최종 제출은 아직이다.
