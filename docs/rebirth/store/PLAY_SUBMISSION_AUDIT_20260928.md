## 실제 Console에서 다시 답할 선언

1. **IARC 콘텐츠 등급을 새 빌드의 실제 접근 가능 화면 기준으로 재응답.** 이번 후보는 카드 전투·몬스터 처치 화면으로 가는 진입점이 없다. 무료 단편 이야기의 문구와 그림에 남은 폭력·공포 묘사가 있는지 확인하고 있는 그대로 답한다. 숨겨진 구버전 코드만으로 전투가 플레이 가능하다고 선언하거나, 검토 없이 폭력이 없다고 단정하지 않는다. [IARC 질문지 안내](https://support.google.com/googleplay/android-developer/answer/9859655?hl=en-GB)는 정확한 응답을 요구하며 등급은 국가별 기관이 결정한다.
2. **타깃 연령을 개인정보 방침과 일치시킬 것.** 사이트는 만 14세 미만을 대상으로 하지 않는다고 쓴다. Play의 `13–15` 그룹을 선택하면 13세도 대상에 넣는 셈이므로 현 문구와 충돌한다. **16–17 및 18+**가 현재 문구와 더 일치하는 출발점이지만, 실제 마케팅 자산·기능·법적 대상과 함께 결정한다. 미성년자 그룹을 선택하면 관련 [타깃 연령·Families 안내](https://support.google.com/googleplay/android-developer/answer/9867159?hl=en)를 검토해야 한다.
3. **광고, 앱 접근, 개인정보처리방침, 계정 삭제 링크, Data safety, 기타 `Needs attention`을 같은 AAB 기준으로 재확인.** 이전 9/21의 `9/11 완료` 표시는 새 버전의 승인 근거가 아니다. 정확한 선언 항목은 Console이 표시하는 [앱 콘텐츠 화면](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en-GB)을 따른다.

## 제출 전에 바로잡을 불일치

- **공개 정책 페이지 갱신 완료, 제출 시 재확인 필요.** 9/28 `https://sn-bow.github.io/Life_Quest/`의 새 게시본 HTTP 200과 상태창 실제 화면 JPEG의 해시 일치를 확인했다. 공개 HTML에는 무료 APK와 미배포 +2013 후보의 차이, `#privacy`·`#delete-account`·`#privacy-ja`·`#delete-account-ja`가 포함된다. Play 제출 직전 URL이 계속 열리는지와 실제 활성 기능에 맞는지 다시 확인한다.
- **Console 등록정보의 텍스트·이미지·AI 자산 선언은 저장했다.** `STORE_AND_TEST_PLAN.md`와 `CLOSED_TEST.md`의 이전 책/이야기·v7 무료 후보 중심 설명은 현재 등록정보 상태가 아니다. 네 언어 문안·언어별 이전 APK 실제 스크린샷 2장·기본 아이콘·피처 그래픽을 저장·재열람했다. 퀘스트 이미지 4장은 `bb33b4b` APK와 시각 동일하고 최신 변경은 성장 보고서 배치에 한정된다. 앞서 보인 `일부 언어에 오류가 있습니다` 경고는 개요에서 다시 편집 화면에 들어간 뒤 사라졌고 리뷰에서는 언어별 누락이 보이지 않았다. AI 생성 두 자산만 지정한 뒤 기본 등록정보 행은 **`검토를 위해 전송 준비 완료`**다. 심사 전송이나 출시가 된 것은 아니다. 현지 가격은 Play 상품에 설정되지 않아 특정 가격을 외부 문구에 확정가로 쓰지 않는다. [상세](PLAY_CONSOLE_DRAFT_STATUS_20260928.md).
- **기존 앱 접근 설명은 무료 경로와 유료 경로를 혼동할 수 있다.** 무료 앱 이용에 계정이 필요한 것처럼 쓰거나, 반대로 모든 기능이 가입 없이 열리는 것처럼 선언하면 모두 실제 동작과 다르다. Plus의 인증/구매 제한과 심사 방법을 따로 적는다.
- **일본어 개인정보 안내가 공개됐다.** `docs/index.html`의 구매 계정·선택적 기존 클라우드 동기화·AI 신고·삭제 및 2.59GB 외부 다운로드에 관한 일본어 본문이 9/28 공개 HTML에 있고, `#privacy-ja`·`#delete-account-ja`를 확인했다. 이는 **Play의 언어별 전체 번역 의무**를 입증한다는 뜻은 아니다. 일본 대상 제출 직전 공개 URL의 표시·링크를 다시 확인한다.
- **현재 제출 완료 판단은 불가하다.** Play Console의 draft·Alpha 임시 출시만 있고 AAB 미업로드·판매자 계정 미설정, Firebase Spark·App Check 미등록을 9/28 확인했다. Alpha의 오래된 출시 노트는 현 유료 후보에 맞는 네 언어 초안으로 수정·저장했으나 게시하지 않았다. 판매자 프로필 양식은 기존 개인 결제 프로필 재사용이 가능하지만 공개 업체명·지원 이메일·명세서 이름 및 개발자·결제 약관 동의가 필요해 제출하지 않았다. 실제 Play 라이선스 거래도 없다. 정확한 상태와 배포 순서는 [`PREDEPLOY_ACCOUNT_AUDIT_20260928.md`](../market/PREDEPLOY_ACCOUNT_AUDIT_20260928.md), [`PAID_RELEASE_CANDIDATE_20260928.md`](../market/PAID_RELEASE_CANDIDATE_20260928.md)를 따른다.
