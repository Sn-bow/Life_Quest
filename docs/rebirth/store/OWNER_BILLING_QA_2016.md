# 본인 계정의 Play 구매 검증 — 2016

2026-10-03. 내부 테스트에 게시된 `2.1.0 (2016)`의 실제 구매 연결 검증 절차다. 크몽 테스터용 비공개 테스트 안내와 구분한다.

- [내부 테스트 참여](https://play.google.com/apps/internaltest/4701695828383701621)
- 앱 패키지: `com.logian.lifequest`
- 임시 표시 이름: `com.logian.lifequest (unreviewed)` — Google 검토 전 내부 테스트의 이름.
- 대상: Play 판매자 본인 계정 한 명. `Life Quest Owner Billing QA` 목록에 등록했고 라이선스 테스트 설정은 `RESPOND_NORMALLY`로 저장했다.
- 서버 연결 검사는 [별도 기록](FIREBASE_DEPLOYMENT_2016.md). **실제 구매 성공은 아직 확인하지 않았다.**

## 설치

1. 휴대폰의 Google Play 계정을 판매자 본인 계정으로 선택한다. 다른 로그인 계정으로 열면 미초대 화면이 나온다.
2. 참여 링크에서 사용 정보 전달 안내를 읽고 본인이 `Accept invite`를 선택한다. 참여 후 나타나는 Google Play 설치 링크를 사용한다.
3. 설정의 앱 버전을 확인한다. 2016이어야 한다. 이전 공개 APK나 개발 APK 설치를 이번 검증의 근거로 쓰지 않는다. 기존 앱과 서명이 충돌하면 삭제 전에 앱의 암호화 백업을 보존하고 별도 기기/테스트 프로필을 우선한다.
4. USB 방식이라면 휴대폰에서 개발자 옵션 → USB 디버깅을 켜고 이 Mac의 연결을 직접 허용한다. 비밀번호/인증 코드 입력은 사용자가 한다.

## 구매 전 준비 상태

- 내부 테스트 게시 및 라이선스 테스트 계정 저장: 완료.
- 서버의 이 앱 구매·주문 접근: 사용자 승인 대기, 초대 미제출.
- Complete 구매 옵션: 비활성 초안. 서버 권한 연결 후 활성화한다.
- 실제 Android Play 설치, Play Integrity/App Check 정상 호출: 미검증.

## 검사 순서

1. 새 테스트 프로필은 0 XP. 무료 미션 하나를 완료하고 작성한 메모가 재실행 후 남는지 확인한다. 실제 개인 정보 대신 테스트 문장을 쓴다.
2. Complete 화면의 네 루트 실제 미션 예시와 현지 Play 가격을 확인한다.
3. Google 연결 후 구매 창에서 **Google의 테스트 카드/테스트 주문 표시**를 확인한다. 일반 카드만 표시되면 구매를 취소하고 계정/라이선스 설정을 점검한다.
4. 무료 테스트 카드 승인 후 서버 검증과 구매 승인, 유료 미션 수락, 외관 및 보고서 접근을 확인한다. 거래 ID/토큰은 공개 문서나 화면에 남기지 않는다.
5. 복원 → 재실행 → 보류/취소 → 테스트 환불을 차례로 확인한다. 환불 후 유료 접근은 해제되고 무료 기록/이미 작성한 완료 메모는 남아야 한다.
6. 선택적 클라우드 기능을 쓴 시험 데이터의 사진 업로드, AI 신고, 계정 삭제도 별도 검증한다. 계정 삭제는 제거할 시험 계정을 명확히 지정하고 사용자의 최종 확인을 받은 뒤 실행한다.

결과에는 버전, Android 버전, 시간, 시나리오, 성공/실패만 기록한다. 테스트 카드 주문은 실제 매출이나 구매 수요로 계산하지 않는다. 이 검증이 끝나야 크몽용 비공개 트랙으로 넘어간다.
