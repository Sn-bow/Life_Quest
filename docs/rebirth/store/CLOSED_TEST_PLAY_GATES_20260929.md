# 유료 후보 비공개 테스트의 Play Console 미완료 항목 · 2026-09-29

범위는 Life Quest `2.0.0+2013`의 **무료 설치 + 선택형 일회성 Plus 구매**다. 이 문서는 9/28까지 저장·재열람한 [Console 초안 기록](PLAY_CONSOLE_DRAFT_STATUS_20260928.md)과 9/29 앱 콘텐츠 재방문 결과를 공식 Google 문서에 대조한 점검표다. **Console의 `Needs attention` 본문을 읽지 못했으므로 계정별 모든 차단 항목을 확정한 목록은 아니다.** 과거에 완료로 보인 선언을 현재 AAB의 유효한 답변으로 간주하지 않는다. 개인 계정 식별자·법적/정산 정보는 기록하지 않는다.

| 영역 | 확인된 상태 | 비공개 테스트 전에 남은 확인/작업 |
| --- | --- | --- |

[스토어 등록정보 안내](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en), [AI 자산별 선언](https://support.google.com/googleplay/android-developer/answer/17262077?hl=en). |

앱 콘텐츠 화면이 열리면 **모든 앱에 답해야 하는 항목**의 현재 상태부터 확인한다. 광고 유무, 타깃 연령, IARC 콘텐츠 등급, Data safety와 삭제 질문, Health apps, Financial features 선언이 해당한다. Play는 비공개 테스트 앱에도 Data safety·Health·Financial 선언을 요구한다. 개인정보처리방침 URL은 Data safety와 실제 계정/데이터 처리에 맞게 입력·검증해야 한다. [앱 콘텐츠](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en), [Data safety](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en), [Health](https://support.google.com/googleplay/android-developer/answer/14738291?hl=en), [Financial](https://support.google.com/googleplay/android-developer/answer/13849271?hl=en).

- **앱 접근/로그인 세부정보:** 무료 사용 경로와 Plus·선택 계정의 제한 경로를 정확히 설명하고 심사자가 접근할 수 있는 방법을 제공한다. 실제 계정이나 인증 비밀은 문서에 적지 않는다. [심사 접근 안내](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en).
- **데이터 삭제:** 앱 안에서 계정을 만들 수 있으므로 인앱 삭제 시작 경로와 앱 밖의 실제 삭제 요청 URL이 필요하다. [Data safety 초안](PAID_DATA_SAFETY_DRAFT_20260928.md)은 Console 제출본이 아니며 삭제 백엔드 운영도 검증되지 않았다. URL과 실제 동작을 일치시킨 뒤 답한다. [계정 삭제 요건](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en).
- **콘텐츠 등급·연령·건강 분류:** IARC는 현재 접근 가능한 화면/이야기에 맞게 다시 응답한다. 타깃 연령은 공개 고지와 맞춰 결정한다. Health 선언은 운동 퀘스트 등 실제 기능을 살펴 분류하며, 코드에 `Health` 능력치가 있다는 이유만으로 양식의 답을 자동 선택하지 않는다. [IARC](https://support.google.com/googleplay/android-developer/answer/9859655?hl=en), [타깃 연령](https://support.google.com/googleplay/android-developer/answer/9867159?hl=en), [Health 선언](https://support.google.com/googleplay/android-developer/answer/14738291?hl=en).
- **Console이 표시하는 다른 선언:** Government apps, COVID-19, News, Advertising ID 및 고위험 권한 사용 등은 `Needs attention`/AAB 검사 결과에 따라 답하거나 적용 제외를 확인한다. 현 화면 오류 때문에 어느 항목이 실제로 남았는지 단정하지 않는다. 권한 선언은 **AAB 추가 후** 요구될 수 있다. [앱 콘텐츠](https://support.google.com/googleplay/android-developer/answer/9859455?hl=en), [권한 선언](https://support.google.com/googleplay/android-developer/answer/9214102?hl=en).

**일회성 Plus 구매 준비는 비공개 테스트의 첫 바이너리 게시와 순서를 구분한다.** 9/29 사용자가 승인한 기존 개인 결제 프로필 연결은 Console 결제 대시보드로 확인했다. 지급 은행 계좌는 아직 없고, 상품 ID·Buy 구매 옵션·지역별 가격도 없다. 연결 뒤 `일회성 제품` 페이지는 새 상품 작성 대신 `일회성 제품을 추가하려면 결제 권한을 APK에 추가해야 합니다`와 `새 APK 업로드`를 표시했다. Google도 Billing Library가 포함된 앱 버전을 **어느 한 테스트 트랙에 게시한 뒤** 상품 구성 기능을 사용하도록 안내한다. 따라서 Plus가 첫 비공개 테스트 빌드에서 바로 작동한다고 약속하지 않는다. 상품을 만들 때 Buy 옵션과 가격·판매 지역을 설정하고 **Active**인지 확인해야 하며 Draft 옵션은 Billing Library 조회에 나오지 않는다. [Billing 준비](https://developer.android.com/google/play/billing/getting-ready), [일회성 상품](https://support.google.com/googleplay/android-developer/answer/16430488?hl=en). 실제 구매·복원·환불과 서버 검증은 운영 인프라가 연결된 Play 설치본에서 별도로 검증해야 한다.

**테스터와 출시 상태:** 임시 출시나 이메일 목록만으로 테스트가 시작되지 않는다. 비공개 트랙을 게시하고 앱 상태가 `Published`가 되어야 opt-in 링크가 표시될 수 있다. 실제 참여자에게 그 링크를 전달해 opt-in을 확인한다. 새 개인 개발자 계정의 **12명 연속 14일 opt-in은 프로덕션 접근 신청 요건**이며, 비공개 테스트 시작 전에 12명을 채워야 한다는 뜻이 아니다. 이 계정에 해당 요건이 적용되는지는 Console의 생산 접근 상태로 재확인한다. [테스트 링크](https://support.google.com/googleplay/android-developer/answer/9845334?hl=en), [개인 계정 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en).

**9/29 지원 경로:** 앱 콘텐츠와 스토어 설정의 로드 오류에 대해 Play Console의 도움말에서 `기타 → 일반적인 Play Console 문제 → Google Play Console`로 지원 티켓을 제출했다. Console에는 `티켓 제출됨`과 `대기 중`이 표시됐고, 사건 번호는 아직 배정되지 않았다. 안내된 이메일 답변 예상은 약 영업일 2일이다. 같은 문제로 중복 티켓을 만들 필요는 없다.

현재 확인된 미완료는 **Alpha AAB 부재와 검토/게시 미완료**다. **앱 콘텐츠·스토어 설정 오류는 필수값의 현재 상태 확인을 막는다.** Plus 판매 테스트에는 **지급 수단·상품/가격·운영 결제 검증**이 추가로 필요하다. 어떤 선언도 제출하거나 AAB를 업로드하지 않았다.
