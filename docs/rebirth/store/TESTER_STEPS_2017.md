# Life Quest 2.2.0 (2017) 사용 확인 안내

2026-10-06 현재 2017은 본인 한 명의 Google Play 내부 테스트 트랙에 게시되어 있습니다. 외부 테스터를 모집하는 비공개 트랙은 보류 중이며, 이 문서는 아직 판매자에게 전달하지 않습니다. 내부 테스트는 Google의 비공개 테스트 12명·연속14일 요건에 포함되지 않습니다. 외부 배포 지시와 실제 비공개 참여 링크·판매자 명단을 확인한 뒤 전달합니다.

## 처음 사용할 때

1. 무료로 시작해 이름과 학습 목표를 입력합니다. 실제 개인정보 대신 테스트용 목표를 사용해도 됩니다. 기본 사용에 로그인·결제·AI 모델 다운로드는 필요 없습니다.
2. 첫 상태창에서 레벨1·0XP를 확인하고 학습 루트 첫 미션을 엽니다.
3. 미션을 수락하고 복습 카드의 질문/답을 작성합니다. 실제 행동을 수행했을 때만 완료합니다. 타이머 종료는 자동 완료가 아닙니다.
4. 완료 화면을 닫고 앱을 다시 열어 진도와 카드가 남는지 봅니다. 같은 미션을 여러 번 눌러도 보상이 중복되지 않아야 합니다.
5. 루트의 ‘내 루트 기록’ 또는 루트 목록의 ‘내 도구함’에서 답을 가렸다 펼치고 내용을 수정해 봅니다. 복습·수정만으로 XP가 늘지 않아야 합니다. 저장한 자기 결과는 구매 없이 계속 사용할 수 있습니다.

## 중단하거나 부담스러울 때

- 미션을 수락하고 카드/메모를 입력한 뒤 화면을 나갔다 돌아옵니다. 임시 저장 안내와 입력 내용이 남는지 확인합니다. 완료 전 초안은 현재 기기에만 저장됩니다.
- ‘오늘은 2분 행동으로 줄이기’를 선택하면 입력은 유지되고 수행할 행동과 보상이 작은 행동 기준으로 바뀌어야 합니다. 계획2분은 실제 집중 시간 측정값이 아닙니다.
- 완료 후 기록을 다시 열면 실제 선택했던 작은 행동 안내와 작성한 결과가 표시되어야 합니다.

## 구매 전에 확인할 수 있는 것

- 네 루트의 첫7개, 총28개 미션은 무료입니다. Complete 일회 구매는 후속56개 미션, 외관3종,30/90일 보고서와 저장 기능을 더합니다.
- ‘미션과 도구 먼저 체험하기’에서 네 루트의 실제8번째 미션과 명시된 예시 결과를 조작합니다. 학습 카드는 답을 가리고, 정리는 항목을 체크하고, 회복은 작은 행동을 선택하고, 관계는 문장을 복사합니다. 예시 체험은 자신의 진도·XP를 바꾸지 않습니다.
- 유료 테스트 구매는 별도의 Google Play 라이선스 테스트 계정에서만 합니다. 일반 테스터에게 실제 결제나 긍정 리뷰를 요구하지 않습니다.

## 화면과 피드백

한국어·일본어·영어·번체 중국어, 작은 휴대폰·태블릿·큰 글씨에서 읽기와 버튼 조작이 가능한지 확인해 주세요. 문제가 있으면 기종, Android 버전, 앱 버전, 재현 순서와 화면을 알려 주세요. 개인 목표·이메일·구매 정보는 가려 주세요.
