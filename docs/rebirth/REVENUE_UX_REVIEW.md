# 수익화 전 사용자 경험 재검토 · 2026-09-20

판단: 첫 행동과 무료 체험의 경계는 이해할 수 있다. 다만 실제 독자가 계속 돌아올 이유와 유료 원고의 가치가 확인되지 않았으므로 **공개 판매 보류**다. 아래는 동일한 412×892 웹 화면을 직접 열고 저장한 근거다. 실물 Android, 실제 사용자 인터뷰 또는 Play 전환 실험이 아니다.

## 1. 오늘 → 상태 맞추기

[01 오늘](screens/revenue-review/01-today.png), [02 상태 맞추기](screens/revenue-review/02-personalize.png).

현실의 행동 문장·분·XP와 현재 책이 함께 보인다. 쉬는 날에도 성장과 선택이 사라지지 않는 방향을 유지한다. 에너지·여유 시간·관심·목표 입력은 추천을 조정하지만, 이 검토에서 좋은 추천이 실제로 지속 행동을 만든다고 증명할 수는 없다. 기존 QA 프로필은 60XP·현실 퀘스트 1개 완료 상태이므로 신규 사용자 활성화 결과로 집계하지 않았다.

## 2. AI → 저장 위치 안내

[03 수정 전](screens/revenue-review/03-ai-privacy-before.png), [04 수정 후](screens/revenue-review/04-ai-privacy-after.png).

**발견 및 수정:** 기기 전용 모드인데도 “수락한 퀘스트는 Firebase에 저장”이라고 표시했다. 현재 프로필과 Cloud 플래그에 따라 실제 저장 위치를 안내하도록 고쳤다. Google 구매 계정 연결도 진행 기록 업로드를 뜻하지 않는다고 설명한다. 회귀 위젯 검사와 새 웹 빌드에서 확인했다. 웹의 ‘기본 추천’ 표시를 온디바이스 모델 실행 성공으로 해석하지 않는다.

## 3. 설정 → 선택 참여 → 평가

[05 참여 전](screens/revenue-review/05-study-consent.png), [06 평가](screens/revenue-review/06-study-rating.png).

내부 테스트 빌드에서만 자발적 참여 메뉴를 제공한다. 참여 전 수집 범위·기기 보관·자동 전송 없음·철회 방법을 읽을 수 있다. 선택지를 누르고 평가 저장 성공을 확인했다. 웹 미리보기 표시가 있고 실제 사용자 집계에서 제외된다. 스크린샷의 점수 3·가격 미정은 개발 기능 확인용 가상 입력이다. 실제 독자 평가로 인용하지 않는다.

보고서 저장 버튼을 누른 뒤 앱 오류는 없었지만, 웹에서 내려받은 실물 파일은 이번 확인에서 확보하지 못했다. 파일 생성 내용·취소·철회·앱 기록 보존은 위젯/단위 검사로 확인했으며 **Android 네이티브 파일선택기 검증은 별도**다. 큰 글자 200%·320px에서 한국어/영어/일본어/중국어 레이아웃 검사도 통과했다.

## 4. 서가 → 조수 우체국 상세

[07 팩 안내](screens/revenue-review/07-pack-value.png).

처음 두 장면이 무료이며 이후 장면의 구매 조건, 현실 행동 20개까지의 진행 조건, 능력치에 영향 없는 테마·표식, 현재 판매하지 않음이 함께 보인다. 무조건 구매를 유도하는 가짜 가격이나 동작하지 않는 결제 버튼을 만들지 않았다. ‘12장면’은 이해되지만 실제 분량이나 몰입의 가치를 보장하지 않는다. 원고를 직접 측정한 결과와 검증 계획은 [REVENUE_VALIDATION.md](REVENUE_VALIDATION.md)에 있다.

가장 중요한 다음 근거는 신규 실제 기기의 D7 행동, 전체 원고의 독자 검수, 실제 결제 복원/환불 안전성이다. 화면을 보기 좋게 만들었다는 이유만으로 판매 준비 완료라고 판단하지 않는다.

## 5. 카드 탐험 → 실제 첫 전투 → 이어 하기

[08 탐험 진입](screens/revenue-review/08-dungeon-entry.png), [09 이전 진행도](screens/revenue-review/09-map-before.png), [10 이전 에너지 안내](screens/revenue-review/10-zero-cost-before.png), [11 수정된 진행도](screens/revenue-review/11-map-after.png), [12 수정된 무료 카드 안내](screens/revenue-review/12-zero-cost-after.png).

첫 전투를 CUA로 실제 진행했다. 초록 슬라임20HP를 공격 카드로20→14→8→2로 줄이고, 적의2×3 공격으로 플레이어HP80→74가 된 다음 승리했다. 12골드와 0EP 카드를 선택한 뒤 웹을 새로고침했다. 탐험은 HP74·골드62·덱11장·첫 방 완료 상태로 복원됐고 일상XP60은 그대로였다. 이는 한 전투의 흐름 확인이며 전체 캠페인 밸런스 검증이 아니다.

**발견 및 수정:** 진행도 분모가 갈림길의 모든 노드11개를 세고 있었다. 한 번의 경로에서 완료하는6단계를 기준으로 바꾸어 첫 승리 후1/6, 보스까지 진행하면6/6이 되도록 했다. 5개 구역의 기존 복원 캠페인 검사에 각 단계 진행도를 추가해 검증했다.

또한 0EP 집중 카드가 실제로 사용 가능한데도 에너지가0이라는 이유로 ‘EP 부족’을 표시했다. 카드별 사용 가능 판정을 전투 상태와 손패·상단 안내가 공유하도록 고쳤다. 비용이 음수인 사용할 수 없는 저주 카드도 사용 가능 수와 활성 버튼에서 제외한다. 새 웹 빌드의 다음 전투에서 에너지0·집중 카드1장 상태가 ‘1장 출격 가능’으로 표시되는 것을 확인했고, 4언어 배지와 실제 에너지/저주 카드 판정6개 회귀 검사가 통과했다.

최종 전체 Flutter368개 통과, 기본 플래그에서 결제 카탈로그1개 의도적skip. 별도23개 연구 관련 검사는 현재 기능 플래그 on/off 경계와 삭제·파일 취소·4언어 큰 글자를 포함한다. Android 연구용 APK의 실물 파일 선택기와 모든 구역의 실제 전투·밸런스는 여전히 미검증이다.
