## 최종 Android 촬영 조건

1. Google 로그인 설정을 반영해 다시 빌드한 `2.0.0+2013` Android 패키지를 AVD에 설치하고 CUA로 화면을 조작·확인한다. 에뮬레이터가 CUA에 노출되지 않으면 셸/ADB 캡처·입력으로 UI 검증을 대신하지 않는다.
