# 최종 상태창 시각 QA와 Play 스크린샷 준비 · 2026-09-28

## 이번 점검에서 직접 본 것

- [휴대전화 상태창 0 XP](qa/hunter-window-0xp-ko.png): 390×844 Flutter Web 캡처. 상태창이 첫 화면의 주인공이며 제목, 레벨, 0/150 XP, 네 능력치가 테두리 안에 들어간다. 임의의 XP가 미리 차 있지 않다. 이 캡처는 새 유료 확장팩을 넣기 전 버전이다.
- [태블릿 가로 상태창](qa/tablet-audit/03-tablet-landscape-status-after.png): 1280×800 Flutter Web 캡처. 생성된 PNG 테두리와 텍스트의 겹침이 수정 후에는 보이지 않는다. 화면 양옆 여백과 하단 탭은 유지된다.
- [태블릿 세로 상태창](qa/tablet-audit/04-tablet-portrait-status-after.png): 800×1000 Flutter Web 캡처. 레벨·XP·능력치가 프레임 안에 보이며 하단 탭도 노출된다. 프레임 아래에 여유 공간이 크지만 잘림은 보이지 않는다.
- [태블릿 상세 상태](qa/tablet-audit/05-tablet-details-after.png): 800×1000 Flutter Web 캡처. 상단 카드와 기본 스탯이 읽힌다. 이미지는 스크롤된 전체 화면을 담지 않으므로 상세 페이지 하단까지 시각 검증한 증거로 사용하지 않는다.

현재 `adb devices -l`은 빈 목록이고 Flutter는 macOS·Chrome만 감지한다. `LifeQuest_API35_16KB` 등 AVD는 설치되어 있다. **최신 유료 확장팩이 적용된 Android 실기/에뮬레이터 화면을 이번 시점에 관찰했다고 주장하지 않는다.** 새 확장팩은 `StatusPackScreen`에 구현되어 있고 320px·일본어 200% 글자, 768/1024px 태블릿의 무료/유료 상태에 대한 위젯 테스트가 존재하지만, 이 점검에서는 루트 빌드와 충돌하지 않도록 테스트나 앱 구동을 하지 않았다. 테스트 존재와 실제 시각 QA는 별개다.

## Play 등록 이미지 판정

[Google Play의 현재 공식 미리보기 이미지 규정](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en)에 따르면 스토어 등록에 최소 2장의 **실제 앱 화면**이 필요하다. 스크린샷은 JPEG 또는 알파 없는 24비트 PNG이며, 짧은 변이 320px 이상, 긴 변이 3840px 이하, 긴 변이 짧은 변의 2배 이하여야 한다. 추천 영역을 위해 앱은 최소 1080px 해상도의 16:9 또는 9:16 화면 4장 이상이 필요하다. 태블릿 영역도 실제 큰 화면을 보여주는 4장 이상, 1080–7680px, 16:9 또는 9:16을 권장한다. 현지화된 그래픽을 Play의 언어별 등록정보에 추가할 수 있다.

| 현재 자산 | 기하학적 점검 | 판정 |
| --- | --- | --- |
| 기존 휴대전화 QA 캡처 390×844 | 844/390=2.16 | **업로드 불가**: 긴 변이 짧은 변의 2배 초과 |
| 기존 태블릿 세로 800×1000 | 1.25 비율, 짧은 변 800 | 내부 QA 자료. 추천 9:16·1080px를 충족하지 않음 |
| 기존 태블릿 가로 1280×800 | 1.6 비율, 짧은 변 800 | 내부 QA 자료. 추천 16:9·1080px를 충족하지 않음 |
| 새 Play 아이콘 512×512 | RGBA PNG, 348,510 bytes | 크기·형식·1MB 제한 충족. 이미지 내용은 최종 시안 별도 확인 |
| 새 특성 그래픽 1024×500 | RGB PNG, 680,484 bytes | 크기·알파 없는 형식 충족. 이미지 내용은 최종 시안 별도 확인 |

기존 화면을 확대하거나 장식 프레임으로 늘려 Play 이미지라고 제출하지 않는다. 새 Android 빌드에서 실제 화면을 해당 비율로 캡처하고, 상태창·돌발 퀘스트 수락/거절·성장 기록·유료 외관 및 보고서 순서로 배치한다. 일본어 첫 세트는 일본어 UI로, 한국어·영어·번체 중국어도 각 언어 UI로 캡처한다. 상점의 가격을 합성하거나 테스트용 `¥700`을 실제 가격처럼 보여주지 않는다. 유료 화면은 Play 테스트 상품/검증된 권한이 준비된 뒤 촬영한다. 개인정보가 보이는 실제 계정 대신 공개 가능한 QA 계정을 쓴다.

## 최종 Android 촬영 조건

1. `build12`의 실제 Android 패키지를 AVD에 설치하고 CUA로 화면을 조작·확인한다. 에뮬레이터가 CUA에 노출되지 않으면 셸/ADB 캡처·입력으로 UI 검증을 대신하지 않는다.
2. 휴대전화 세로는 1080×1920, 태블릿 가로는 1920×1080 등 Play 권장 비율로 **앱 자체 화면을** 캡처한다. 상태줄의 알림·통신사·사적인 정보는 제거한다.
3. 일본어·한국어·영어·번체 중국어 각각에서 첫 화면, 320px 좁은 화면, 큰 글자, 태블릿 가로/세로의 텍스트 잘림·프레임 겹침·탭 동작을 확인한다. 사용자의 실제 결제/복원/환불 경험은 Play 라이선스 거래가 가능한 단계에서 별도로 확인한다.
4. 무료 기능을 먼저 보여주고, 확장팩 스크린샷에는 실제 구현된 세 가지 외관과 기록된 성과만 표시한다. 위젯 테스트의 가상 거래/기록을 사용자 매출·사용 이력으로 포장하지 않는다.

이 문서는 **현재 확인한 시각 증거와 촬영 기준**이다. 최신 Android 화면과 Play 업로드 승인은 아직 검증 결과가 아니다.
