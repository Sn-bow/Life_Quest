# 상태창 내부 콘텐츠 간격 · 2026-10-03

사용자가 외곽 프레임 패딩 확대를 거절한 뒤, 내부 정보 사이의 간격·배치를 수정하라고 승인했다. 이번 소스는 `33ab5f4`다. `HunterSystemFrame`과 상태창의 외곽 패딩, 생성 raster 자산은 변경하지 않았다.

## 변경
- 레벨과 이름의 간격12→20dp, 기본 휴대폰에서 메뉴 아래8→16dp, 칭호와 경험치 사이8→14dp.
- 경험치/루트/능력치 사이18dp 간격. 능력치의 두 열 사이20dp, 두 행 사이10dp, 포인트 위12dp. 태블릿·큰 글꼴은 한 열과12dp 행 간격,28dp 섹션 간격을 쓴다.
- 짧은 휴대폰은12dp 섹션·6dp 행 간격을 사용하고 루트의 중복 진행 막대를 생략한다. `시작 · 0/21` 같은 단계·진도 숫자와 루트 진입은 그대로 유지한다. 글자 축소는 추가하지 않았다.

Android API35/16KB 에뮬레이터에서 촬영하고 직접 확인했다. 검증 후 기본 크기·글꼴 배율로 복원했다. 관련 기존 위젯 검사53개 통과, analyze 오류 없음. 네 언어와320/800/1280dp·200% 검사는 위젯 범위이며, 이번 native 캡처는 한국어다. 실물 기기나 실제 구매 검증을 뜻하지 않는다.

이 변경은 기존 AAB에 포함되지 않는다. Play 업로드 전 최신 소스로 재빌드·파일 검사해야 한다. 거절된 외곽 패딩 시안 `spacing-review.apk`와 이번 `content-spacing.apk`를 혼동하지 않는다.
