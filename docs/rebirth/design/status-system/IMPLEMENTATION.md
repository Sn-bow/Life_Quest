# 상태창 구현 체크포인트 — 2026-09-22

## 이번 구현

- `SystemStatusHeader`: 생성 배경, 상태/레벨/XP/네 능력치 중심 첫 화면. 숫자는 현재 저장 데이터. 돌발이 없을 때는 첫 추천을 먼저 보여주고 시스템 대기/타이머는 아래로 이동한다.
- `SystemOfferCard` / `SystemJournal`: 검수 템플릿 4종, 수락/거절/중단/수행 완료/만료, 설정 off, 표시 한도와 절대 마감 시각 저장.
- `SystemRewardScene`: 저장 뒤 결과 장면. 퀘스트 실제 보상과 업적 추가 XP를 구분하고 레벨 전후/실제 자동 배분만 표시.
- `GrowthReceipt`: 기존 프로필과 같은 저장 payload에 지급 사실을 기록. 성장 기록에서 완료 장면 다시 열기. 최근 30건 표시, 전체 저장 기록 유지.
- 추천 퀘스트의 수락 XP 고정. 기존 사용자 반복 퀘스트의 완료 보상/리셋 표시 정정. 과거 정확한 지급량은 추정해 생성하지 않음.
- 월요일 0시 기준 주간 집계. 퀘스트 삭제/일일 리셋 뒤에도 새 완료 기록으로 집계.
- 모션 감소/큰 글씨/네 언어 대응. 명조 제목용 Noto Serif KR (OFL 1.1)과 기존 본문 글꼴 사용.

## 정확성 수정

기존 첫 완료는 퀘스트 20 XP + 업적 50 XP를 지급하지만 반환 결과는 20 XP였다. 새 결과/오늘 퀘스트 합계는 지급 총량을 표시하며, 내역은 20 + 50으로 분리한다. 레벨업 시 잔여 XP 감소도 실제 레벨/잔여값으로 기록한다.

저장에 실패하면 성공 모달을 띄우지 않는다. 같은 완료를 다시 저장할 때 XP를 다시 지급하지 않는다. 의뢰 수락 실패 후 rollback된 객체도 ID로 다시 찾아 재시도한다. 읽을 수 없는 백업은 기존 검증 경계를 유지한다.

## 범위와 남은 점

- 돌발은 현재 앱 내 발생이다. 백그라운드 푸시, 잠금 화면 상태창, AI 돌발 문장 생성까지 구현한 것은 아니다.
- 현재 성장 영수증은 일상/주간/월간/연간/돌발 퀘스트와 그때 발생한 업적 보상이다. 타이머·탐험·수동 스탯 배분의 별도 이벤트 기록과 전일 마감 스탯 전체 비교는 후속이다. 화면 문구도 ‘오늘 퀘스트’로 구분했다.
- 메인 상태/의뢰/보상/기록 경로를 바꿨다. 기존 카드 전투와 모든 설정 화면을 새 시안으로 전면 교체한 것은 아니다.
- 새 중국어 문자열은 기존 지원 언어인 간체다. 대만 번체 추가 현지화는 별도 작업이다.
- 결제·광고·클라우드/연구 수집 기능의 기본 off 유지. 새 수익 검증이나 Play 배포 완료로 표현하지 않는다.
- 스토어 스크린샷은 새 Android 실기 검증 후 교체한다. 여기 QA 이미지는 실제 Flutter Web QA 빌드이며 출시 Android 화면이라고 주장하지 않는다.
