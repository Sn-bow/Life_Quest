# 상태창 UI 조사와 구현 방향 — 2026-09-22

사용자 요청: 여러 현대 판타지 웹툰·소설에서 주인공이 보는 상태창을 참고하고, 조사에 근거해 실제 앱 디자인과 연출을 구현한다. 사용자가 앞서 디자인 결정 전권을 위임했으므로 세 가지 생성 컨셉 중 Night Registry를 작업 기준으로 선택했다. 사용자가 별도로 시안을 선택한 것으로 기록하지 않는다.

소설 전문이나 무림로그인 본편의 상태창 화면까지 열람한 조사는 아니다. 작품별 소개에서 얻은 서사 구조와 직접 본 공개 장면의 시각 표현을 구분했다. 위 적용 방향은 제품 설계 해석이며, 마케팅 효과나 전환율이 검증됐다는 뜻이 아니다.

## 선택한 시각 언어

- Night Registry: 먹색 `#090F14`, 은백색 본문, 금색 `#DABC83` 성장, 옥색 `#9EDCD0` 시스템 의뢰.
- 첫 화면의 우선순위: 상태창 → 내 레벨/이름 → 실제 XP/네 능력치 → 돌발 의뢰 → 일상 행동.
- 네 능력치는 공통 영역에서 비교하고, 의뢰에만 얇은 테두리를 사용한다. 반복 둥근 카드 대시보드 밀도를 낮춘다.
- 글자는 실제 Flutter 텍스트. 접근성 글자 확대, 번역, 스크린리더 때문에 목업 안의 이미지 글자를 재사용하지 않는다. 본문은 기존 Noto Sans KR를 유지하고 상태창·레벨·의뢰 제목에는 Noto Serif KR를 사용한다. [Google Fonts 공식 배포본](https://github.com/google/fonts/tree/main/ofl/notoserifkr)의 SIL OFL 1.1 글꼴이며 라이선스를 함께 번들한다.
- 배경만 ImageGen으로 제작한 독창적 도시 경계 이미지. 작품의 캐릭터/로고/패널을 제품에 쓰지 않는다. 출처·프롬프트는 `assets/images/ui/status_threshold_v1.md`.
- 원본 시안의 71 XP는 컨셉 데이터. 실행 검증은 신규 QA 프로필 0 XP에서 실제 버튼 조작으로 획득한다.

## 구현 연출

- 의뢰 등장: 360ms 페이드/짧은 이동. 수락/거절을 동등하게 제공.
- XP 갱신: 650ms 실제 비율 변화. 실행 때마다 허구의 XP를 채우지 않음.
- 완료/레벨업: 저장 성공 뒤 320ms 결과창. 실제 XP, 퀘스트/업적 내역, 레벨 전후, 실제 스탯 변화.
- 저장 오류: 성공 장면 대신 재시도. 중복 지급 방지.
- 모션 감소 시 즉시 표시. 거절·중단·만료에 XP 삭감 없음.
- 돌발 의뢰는 앱 안에서만 발생. 하루 최대 1회, 최근 7일 최대 3회, 동시에 1개. 첫 일상 행동 이후 시간 예산이 남으면 제안. 수락 기한 2시간, 수락 후 수행 기한 20분.
- 초기 돌발 행동은 검수된 네 개 템플릿이며, AI가 새 행동을 생성했다고 표시하지 않는다. 기존 일상 온디바이스 추천과 별개로 빈도·기한·보상은 앱이 관리한다.
