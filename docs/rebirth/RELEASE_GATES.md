## 외부 상태 확인

- 2026-09-20 Firebase CLI의 접근 가능한 프로젝트 목록은 비어 있었다. gcloud의 기존 프로젝트 조회는 권한 없음/없음으로 실패하여, 이것만으로 현재 복원 가능 여부를 단정하지 않는다. 9월17일 Console에서는 삭제 상태를 확인했다. 복원 또는 새 프로젝트 방향을 사용자에게 질문한 상태다. 결제 계정 연결이나 비용 발생 작업은 수행하지 않았다.
- 실물 Android가 연결되지 않았다. 전용 에뮬레이터는 있으나 실물 검증을 대신하지 않는다. 사용 가능한 기종과 실제 테스터 확보 여부를 질문했다. 가짜 테스터/참여 증거를 만들거나 누구에게 모집 메시지를 보내지 않았다.
- Play 기본 등록정보의 EN/KR 새 문구를 임시보관함에 저장하고 성공 상태를 확인했다. 아이콘 파일 선택은 `Not allowed`로 재차 차단됐다. ChatGPT Chrome 확장의 ‘파일 URL에 대한 액세스 허용’을 사용자에게 안내했다. 제한을 우회하지 않았다.
- 대시보드는9월20일 최초 열기와1회 새로고침 모두 Console의 예기치 않은 오류가 발생하여 최신 테스터 숫자를 읽지 못했다. 마지막 확인값은9월17일0명/프로덕션 접근 없음이다. [공식 개인 계정 테스트 조건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)은12명 연속14일이다.

Cloud/Billing/Ads 기본 비활성은 유지한다. 서버 준비만 끝났다고 결제를 켜지 않는다. 신규 조회 목록은 story_tide_postoffice_01 하나이며 첫2장면은 구매/행동 없이 열렸다. 과거 SKU는 기존 영수증의 검증·복원 호환성만 유지하고 신규 판매 목록에 넣지 않는다.
