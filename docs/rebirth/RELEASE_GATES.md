## 구분해야 할 증거

- 직접 APK 공개는 Play 출시가 아니다. [공식 개인 계정 테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)은 에뮬레이터·가짜 계정·APK 다운로드수로 대체할 수 없다.
- 다운로드는 고유 설치자나 재방문이 아니다. 개발자가 검증하려고 내려받은 파일도 집계될 수 있다.
- 무료 모델의 API 호출료가 없다는 것과 Firebase 서버 운영비가 없다는 것은 다르다. 현재 무료 Spark에 접근 차단 저장소만 준비했으며 과금 계정이나 Blaze를 연결하지 않았다.
- 현재 사용량 하한은 잔여20%다. 사용자 기기·계정·테스터에 관한 정보가 없을 때 이를 만들어 채우지 않는다.
