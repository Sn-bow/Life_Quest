# 무료 사용 → 유료 검토 흐름 점검 · 2026-10-03

사용자 목표는 돈을 지불할 이유가 있는 제품과 비공개 테스트 배포까지다. 이번 기록은 목표를 구현/QA만으로 낮추지 않는다. 원복한 메인 상태창 디자인은 유지했다.

## 수정 전 실제 Android 관찰

API35/16KB 에뮬레이터, 한국어, 1080×1920, 원본 `2.1.0+2014 complete.apk` 사용. 기존 합성 `QA` 프로필이며 실제 사용자 행동·구매 수요 자료가 아니다.

1. **상태창 → 현재 루트** (`01-status`, `02-route`): 0 XP, 0/21 시작. 영어 목표는 이전에 영어로 만든 프로필의 저장된 목표다. 언어 변경으로 사용자 입력을 번역하지 않는다.
2. **미션 읽기·수락** (`03-mission`): 일반 버전과 작은 행동 선택, 첫 실제 안내 두 단계가 보인다.
3. **메모 → 뒤로 → 재진입** (`04-note-before`, `05-note-lost`): 입력한 `QA draft: learn one concept`가 사라짐을 직접 재현했다. 완료 전 메모는 화면 컨트롤러에만 있었고 다시 여는 초기화/저장 처리가 없었다. **수정 대상.**
4. **완료·다음 단계** (`06-reward`): 테스트 문구를 다시 입력하고 합성 완료했다. 첫 미션10 XP+첫 완료 업적50 XP, 총60 XP가 저장되고1/21로 이동했다. 샘플 보상이나 선입력 XP가 아니다.
5. **유료 예시** (`07-paid-sample`): 루트의8번을 누르면 실제 후속 미션이 열린다.9번은 경계 안내를 보이고 구매 화면으로 간다.
6. **구매 검토** (`08-complete`, `09-complete-purchase`): 유료 혜택은 기능 목록뿐이며 실제 예시는 이전 화면에만 있다. 네 루트의 실제 안내를 이 화면에서 비교할 수 없었다. 실제 Play 가격 미조회 표시는 정직하게 유지된다. **콘텐츠 판단 경로 개선 대상.**

모든 채택 이미지를 파일로 저장한 후 직접 열어 확인했다. 읽기/버튼 도달 여부는 확인했으나 TalkBack 전체 흐름과 실물 제조사 키보드 검사를 대신하지 않는다.

## 구현한 수정

소스 `b968d04`, 버전2.1.0+2015.
- 미션 메모를 프로필·미션별로 분리해 기기에 자동 임시 저장한다. 마지막 입력의 쓰기 순서를 보장하고 저장 실패를 표시하며 다시 시도할 수 있다. 성공하지 않은 입력을 버리고 뒤로 나가지 않는다.
- 초안은 완료 전 클라우드 전송/진행 백업에 포함하지 않는다. 완료하면 기존의 진도·XP 저장과 함께 실행 기록에 남기고 초안을 정리한다. 프로필 삭제 시 잔여 초안도 지운다. 네 언어 앱 안내·개인정보 안내를 실제 범위에 맞췄다.
- 질문/답변처럼 나눈 완료 메모의 줄바꿈을 저장/백업 복원에서도 보존한다.
- 구매 화면에서 네 루트의 실제8번째 미션과 작은 행동 버전을 읽는다. 별도 홍보용 가짜 예시가 아니라 배포 콘텐츠 자산을 직접 사용하며, 계정/결제/진도 변경 없이 볼 수 있다. 무료28개+추가56개를 명확히 표시한다.
- 메인 상태창의 프레임·간격·능력치 배치는 변경하지 않았다.
