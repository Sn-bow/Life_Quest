# 가입 복구 수정 · 2026-10-06

## 이번 작업의 종료 범위

사용자가 계속 진행 중인 작업이 무엇인지 물었다. 구매·복원·환불·결제 실패 확인은 이미 끝난 범위라고 설명했고, 이번 가입 수정의 최종 검사·빌드·상태 저장까지만 마무리한다고 알렸다. 추가 기능 개발, 검사 환경 확대, 새로운 계정 생성이나 외부 테스터 배포로 이어가지 않는다. 외부 모집용 비공개 트랙은 계속 보류한다.

최종 앱 소스는 `764de80`, 로컬 후보는 `2.2.1+2018`이다. 현재 Play 본인 내부 설치본은 `2.2.0+2017`이며 이 수정본을 업로드한 것이 아니다. 메인 상태창 디자인·Complete 상품·서버 설정은 바꾸지 않았다.

## 발견한 문제와 수정

- 가입 화면에 남아 있던 초기 퀘스트 8개 자동 생성을 제거했다. 새 클라우드 프로필도 공통 초기화 경로를 사용해 0XP·빈 기록에서 시작한다.
- 인증 직후 화면이 프로필 로딩으로 넘어가지 않도록 가입 완료까지 기다린다. 사진 업로드나 프로필 저장 실패 시 새 인증 계정을 또 만들지 않고 같은 계정의 설정을 재시도한다.
- 기존 프로필이 있으면 이름·선택 사진만 트랜잭션으로 갱신한다. 기존 XP·루트·카드·기록을 초기 데이터로 덮어쓰지 않는다. 계정 전환과 구매 전용 신원도 검사한다.
- 가입·로그인 비밀번호의 앞뒤 공백을 임의로 제거하지 않는다. 부분 가입 뒤 뒤로 가면 이번에 만든 신원만 로그아웃하고 계정을 삭제하지 않는다.
- 한국어·영어·일본어·번체 중국어에 재시도 안내를 추가했다. 320dp 전화와 1280dp 태블릿, 200% 글자 배율에서 실제 가입 위젯의 재시도 버튼 접근과 진행 경로를 검사했다.

코드에서 확인한 덮어쓰기 위험의 수정이며 실제 고객 기록 손실이 발생했다는 증거는 없다.

## 검사 결과

- 기본 설정 전체 실행: 621개 통과, 의도적 2개 skip, 문서의 대소문자 기대값 1개 실패. 해당 문서 검사를 바로잡은 뒤 문서/기본 monetization 검사 6개가 모두 통과했다. 전체 실행을 다시 한 것으로 기록하지 않는다.
- Cloud/Billing 활성 설정의 가입·초기 프로필·상품 관련 검사: **22개 모두 통과**. 실제 SessionGate의 가입 중 프로필 로딩 차단도 이 실행에 포함된다.
- 전체 `flutter analyze --no-pub`: **No issues found**, `git diff --check` 통과.
- 중간 활성 설정 실행에 포함했던 기본 monetization-off 검사는 의도적으로 반대 플래그를 넣어 실패했다. 기본 설정으로 다시 실행한 6개 검사에서 통과했으며 제품 결함으로 기록하지 않는다.
- 첫 `--no-pub` 릴리스 빌드는 생성된 plugin registrant가 릴리스에 없는 개발용 splash/integration-test 플러그인을 참조해 실패했다. 앱 코드를 추가 변경하지 않고 일반 릴리스 명령으로 생성 정보를 갱신해 AAB 빌드를 성공시켰다. 이 실패 로그와 최종 빌드 로그를 분리해 보존했다.
- 서명된 최종 AAB/APK 빌드 완료. AAB **40/40** 검사 통과, API35 ARM64 표본 다운로드65,513,698bytes. APK의 예상 업로드 인증서·v2서명·16KB ZIP정렬·패키지/2018/2.2.1/target36 검사 통과. [2018 빌드 기록](../product-2018-build.json)과 [아티팩트 검사](../product-2018-inspection.json)에 파일 크기·SHA256을 남겼다. 기존2017 파일은 덮어쓰지 않았다.

위 가입 검사는 Firebase SDK mock과 가짜 Firestore를 사용하는 회귀/위젯 검사다. 실제 서버의 새 가입·사진 업로드·계정 삭제 성공이나 2018의 실제 Play 설치 증거로 바꾸어 말하지 않는다. 2017 본인 휴대폰 테스트 카드 결과는 [별도 거래 기록](play-test-purchase-20261006.md)에 유지한다.

## 저장한 준비 상태

사용자가 새 Play 검사 기기의 Google 로그인을 완료했고 실제 Play 홈·지정 소유자 계정 표시를 확인했다. 해당 기기에 Life Quest를 설치하거나 App Check 성공을 확인한 것은 아니다. 이번 종료 범위에 맞춰 이 검사를 확대하지 않는다.

[심사 접근 준비](../store/APP_ACCESS_2018.md)는 전체 제한 기능의 재사용 가능한 심사 접근이 아직 준비되지 않았음을 명시한 문서다. 심사 제출이나 외부 비공개 게시를 완료했다고 기록하지 않는다. 실제 고객 매출 또는 구매 수요 확인은 없으며 원래 제품 목표를 완료로 낮추지 않는다.
