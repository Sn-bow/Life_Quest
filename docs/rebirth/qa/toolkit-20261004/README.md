# 제품 사용 흐름 보완 · 2026-10-04

사용자 목표는 사람들이 반복 사용하고 돈을 지불할 만한 완성 제품이다. 출시 설정·검사 통과·내부 테스트 게시로 그 목표를 대체하지 않는다. 이 변경은 목표를 수행하는 제품 작업이며, 실제 고객 구매나 매출의 증거는 아니다. Play/Firebase의 기존 상태는 보존했고 이번 작업에서 외부 배포 설정은 변경하지 않았다.

## 실제 흐름에서 확인하고 고친 점

| 단계 | 확인한 문제 | 최종 동작 |
| --- | --- | --- |

| 저장/오류 | 새 필드와 기존 메모가 따로 저장되면 유실/충돌 가능. | 프로필별 순차 초안 저장, 구버전 일반 메모 호환, 완료 시 XP와 같은 저장 단위, 휴대용 백업 포함. 수정 저장 실패는 원래 값 복구. 완료 저장 실패 후 재시도 동안 입력을 잠가 결과 불일치를 막는다. |

메인 상태창의 원복된 프레임/내부 간격은 변경하지 않았다. 새 수제 SVG/HTML/Canvas 아트나 모방 IP 자산은 없다. 추가 유료 서버/API나 구독을 만들지 않았다.

## 검증 범위

- 전체 Flutter 599 통과 / 기존 기본설정 1 skip. 마지막 기록 표시·입력 보호 수정 후 Cloud/Billing on 관련 80 통과. 정적 분석 문제 없음.
- 새 검사에는 이전 초안 호환, 다국어/줄바꿈, 저장 실패·재시도, 프로필 재시작, 백업 왕복, 구매 없는 수정, 미완료 단계 수정 차단, 보상 중복 방지와 4언어 × 320/1280dp × 200% 글씨에서 실제 조작이 포함된다.
- 새 브라우저 릴리스 빌드의 실제 Flutter 화면을 CUA로 확인했다. 390×844 휴대폰 및 1280×800 태블릿. 입력→나갔다 재진입→초안 복구→15분에서2분 전환→완료(+10 XP, 71→81)→카드 복습을 수행했다. 기존 로컬 합성 QA 프로필이며 실제 사용자 성과가 아니다.
- `phone-workspace.png`: 작성 중 복구한 질문/답. `phone-record.png`: 완료한 실제 작성 내용. 캡처는 웹 화면이며 Android 실기 캡처가 아니다. 최종 시각 보완 전 캡처에는 ‘남긴 메모 없음’ 문구가 남아 있고, 후속 `*-final.png`를 최종 화면으로 사용한다.
- Play 결제/복원/환불, 실물 Android 제조사별 동작, 전체 TalkBack 여정, 고객 지불 의사는 위 검사로 검증되지 않는다. 기존 내부 2016과 새 로컬 2017을 혼동하지 않는다.

## 후속 실제 스크롤 회귀 수정

구매 미리보기에서 선택한 루트/체크 상태가 ListView 화면 밖으로 벗어났다가 돌아오면 사라지는 경우를 독립 회귀 검사로 재현했다. `JourneySamples`의 자동 보존과 펼친 하위 상태 유지로 수정했고 관련19개 검사가 통과했다. 단순 컴포넌트의 첫 렌더 검사는 이 문제를 발견하지 못하므로 실제 스크롤 왕복을 검사한다. ‘미션과 도구 먼저 체험하기’로 제목을 맞췄다.

`phone-toolkit-final.png`와 `tablet-toolkit-final.png`는 최종 도구함 UI다. 입력은 합성 예시다. 이 화면은 마지막 구매 미리보기 보존 수정에서도 바뀌지 않았다. 이전 입력을 실제 페이지 새로고침 후 다시 읽었고 81XP·1/21을 확인했다. `phone-purchase-sample.png`는 펼친 실제 체험 카드이며 제목 변경 전 촬영했다.

2017 ARM64 signed APK를 기존 개발 에뮬레이터에 데이터 보존 업데이트로 설치 성공했고, 패키지 조회로 versionCode2017 / versionName2.2.0 / targetSDK36을 확인했다. 새 Android UI 전체를 직접 조작한 것으로 확대 해석하지 않는다. 브라우저/위젯 검사와 Android 설치 검사는 다른 범위다.

## 최종 산출물 확인

빌드 소스는 `cb99d7febeb4e727155c4e545577653bab060617`이다. 마지막 구매 미리보기 수정까지 포함해 signed AAB와 ARM64 APK를 다시 만들고 APK를 데이터 보존 업데이트로 설치했다. 최종 정적 분석 문제0건, AAB40/40, APK업로드인증서·v2서명·16KB ZIP정렬 통과. [파일 해시와 검사 범위](../../product-2017-build.json)를 사용한다. 전체599/관련80은 마지막 미리보기 변경 이전 검사이고 마지막 변경은 회귀19개로 검증했다.

`purchase-checklist-final.png`는 최종 브라우저 앱에서 구매 예시의 정리 루트를 선택해 항목을 체크하고 스크롤 왕복 후 상태가 유지된 화면이다. 고객이 작성한 데이터가 아닌, 명시적으로 표시된 앱 내 체험 예시다. 새2017을 Play에 올리거나 기존2016을 대체하지 않았다.
