# 실행 기록·이어가기 제품 점검 · 2016

2026-10-03. 앱 소스 `6594fdc`, 2.1.0+2016. 사용자 목표는 사람들이 비용을 지불할 이유가 있는 완성 제품과 비공개 테스트 배포다. 이번 변경은 제품 흐름 개선이며 그 전체 목표의 완료 선언이 아니다. 메인 상태창 프레임·내용 간격은 원복된 그대로다.

## 확인한 문제와 수정
- 이전 설치본에서 완료한 기록도 ‘미리보기’라고 표시됐다(`00-before-completed-preview.png`). 이 사진의 기존 미션은 일반 버전으로 수행한 합성 기록이다. **작은 행동 오표시는 이 사진만으로 증명하지 않는다.** 코드의 기록 조회가 저장된 `shortVersion`을 무시하고 일반 안내를 보여주는 것을 확인했고, 작은 행동 수락→완료→기록 재열람 테스트로 검증했다.
- 완료 메모를 루트 전체에서 모아 읽고 다시 쓰는 경로가 없었다. ‘나의 실행 기록’에서 목표, 완료 순서/날짜, 실제 선택 버전, 직접 남긴 메모를 모아 보고 복사한다. 각 장의 회고 미션에 쓴 메모가 ‘내가 남긴 방법’에 모인다. 빈 메모의 결과를 만들어 내거나 계획 시간을 실제 집중 시간으로 표시하지 않는다.
- 다른 루트 진행 후 이미 수락했던 미션을 다시 열 때 상태창이 다른 루트를 가리킬 수 있었다. 미션 열기에서 선택을 먼저 저장하며, 저장 실패 때 오류/재시도로 처리한다. 진도/보상은 열기만으로 바뀌지 않는다.
- 기기 프로필 삭제 뒤 열린 기록 화면도 즉시 갱신하도록 삭제 완료 알림을 보완했다. 사용자 자신의 완료 기록은 구매 없이 열람/복사할 수 있다.
