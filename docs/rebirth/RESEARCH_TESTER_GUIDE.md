# 경계의 서가 · 비공개 사용성 테스트 안내

이 버전은 판매하지 않는 검토용 앱입니다. 앱을 평가하기 위해 결제할 필요가 없습니다. 계정 가입 없이 기기에 기록을 저장하며, AI 모델 설치도 선택입니다. 현재 단계에서 사용할 Android 기종과 모델의 실물 성능은 확인이 필요합니다.

## 참여 시작

1. 검토용 APK를 설치하고 ‘이 기기에서 시작’을 선택합니다. 기존 사용자는 기록을 지우지 말고 그대로 시작하세요.
2. 첫 퀘스트를 완료하기 전에 **성장 → 설정 → 14일 사용성 테스트**를 엽니다. 설명을 읽고 원할 때만 참여합니다. 이미 앱을 사용했어도 참여할 수 있지만 신규 사용자와 구분됩니다.
3. 화면 아래의 무작위 참여 코드를 운영자에게 비공개로 전달합니다. 이름, Google 계정, 목표 내용이나 백업 파일은 보고서에 필요하지 않습니다.
4. 평소 생활에 맞게 사용하세요. 매일 접속하거나 특정 수의 퀘스트를 채우는 숙제는 없습니다. 퀘스트를 건너뛰거나 앱을 사용하지 않아도 괜찮습니다.

기본 추천·수동 퀘스트·무료 단편만으로 테스트할 수 있습니다. 별도 AI 모델은 약2.59GB를 내려받아 기기에서 실행합니다. 실제 사용할 기기의 저장 공간과 동작을 확인한 뒤 선택하세요. AI를 설치하지 않은 경험도 중요한 피드백입니다.

## 이야기 평가

성장 → 경계의 서가에서 「조수 우체국」의 처음 두 장면을 읽을 수 있습니다. 두 장면에서 선택까지 끝낸 뒤 테스트 메뉴로 돌아오면 평가가 열립니다.

‘매력’과 ‘지불할 의향이 있는 최대 금액’을 고르고 **평가 저장**을 누르세요. ‘구매하지 않을 것 같아요’와 ‘아직 모르겠어요’도 동등한 답변입니다. 이 선택은 구매·예약·출시 약속이 아닙니다. 전체 원고를 별도로 검토한 경우 운영자에게 그 사실을 알려 무료 체험 응답과 구분합니다.

## 종료와 보고서

참여 시점으로부터 14일이 지난 뒤 같은 메뉴의 **결과 파일 저장**을 누릅니다. Android 파일 선택 창에서 원하는 위치에 JSON 파일을 저장하고, 운영자와 합의한 비공개 경로로 전달하고 싶은 경우에만 공유하세요. 앱이 자동으로 보내지는 않습니다.

파일에는 코드, 참여 후 날짜 구간별 완료 수, 이야기 체험 여부, 평가와 기록 이상 표시만 있습니다. 실제 행동이나 결제 내역을 인증하는 파일은 아닙니다. 14일이 지나면 사용 행동 수집이 멈추며, 앱은 계속 사용할 수 있습니다.

참여를 중단하려면 **참여 중단 및 테스트 기록 삭제**를 선택합니다. 퀘스트·이야기 진행은 유지됩니다. 이미 직접 공유한 파일은 기기에서 삭제되지 않습니다. 사용성 연구를 위한 앱 보고서와 Google Play의 비공개 테스트 참여 자격은 별개입니다.

## 운영자 기록표

아래는 인터뷰 항목입니다. 아직 답변이나 실제 참가자는 없습니다.

- 처음 무엇을 하면 되는지 이해했는가? 어디에서 멈췄는가?
- 현실에서 해야 할 행동과 이야기 속 선택을 구분했는가?
- 다시 열게 만든 이유는 무엇인가? 앱 알림, 운영자 연락, 자발적 필요 중 무엇이었는가?
- 무료 체험 다음을 읽고 싶었는가? 원하지 않았다면 어떤 점 때문인가?
- 가격 선택지를 보여 주기 전에 기대한 가격과 구매하지 않을 이유는 무엇인가?
- 구매 시 받는 내용과 추가 현실 행동 조건을 정확히 이해했는가?
- 불편한 추천·읽기 어려운 글자·저장이나 복원 실패가 있었는가?

참여 코드 명단과 전달받은 파일은 공개 Git 저장소에 올리지 않습니다. 응답을 실제 구매나 시장 전환율로 표현하지 않습니다. 전체 원고와 가격 검토 기준은 [수익화 검증 계획](REVENUE_VALIDATION.md)에 있습니다.
