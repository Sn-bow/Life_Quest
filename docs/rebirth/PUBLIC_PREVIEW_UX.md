# 공개 다운로드 흐름 검토 · 2026-09-21

현재 공개 페이지를 먼저 CUA로 캡처한 다음 로컬 구현을1280px와390px화면에서 열고 각 화면을 직접 확인했다. 데스크톱 브라우저의 반응형 확인이며 실제 Android 앱 캡처가 아니다. 기준은 기존 LifeUp/Finch의 명확한 핵심약속/첫행동 구성과 이 프로젝트의 생성된 서가 아트다. 외부 작품 이미지를 옮겨 쓰지 않았다.

1. 기존 페이지에는 개인정보만 있고 설치 경로가 없었다. [변경 전](screens/public-preview/site-before.png). 제품 첫 설명과 무료 시작 진입을 추가했다.
2. [데스크톱](screens/public-preview/site-desktop.png)과[휴대전화 너비](screens/public-preview/site-mobile.png)에서 오늘의 행동→다음 장면이라는약속, 세 세계의 생성원화, Android공개프리뷰라는배포상태가보인다. 배경·표지를코드로그리지않았다. 휴대전화에서는본문·버튼이이미지보다먼저나오며가로넘침이없다.
3. 첫화면의무료시작을누르면[다운로드와의견](screens/public-preview/site-download-mobile.png)으로이동한다. APK직접배포/Android8+/ARM64와Play등록전임을다운로드버튼위에표시한다. 버튼은기본설치파일,두번째링크는릴리스해시/상세정보다. 이메일은실제로발송하지않았고테스트의견을만들지않았다.

앵커와의미있는제목·링크·대체텍스트를사용한다. 사용순서설명의밝은금색작은글자는어두운녹색으로고쳤다. 브라우저390px에서버튼과문구가겹치지않는다. 스크린리더/TalkBack·실제휴대전화·스토어다운로드는이캡처로검증한것이아니다. 공개파일과사이트의실제HTTP검사는배포기록에별도로남긴다.

4. 실제 배포 후 [공개 사이트](screens/public-preview/site-published-desktop.png)를 다시 열어 제품 설명·다운로드 버튼을 확인했다. 다운로드 링크는 공개 GitHub APK와 일치했고, 별도 HTTP 다운로드의 전체 파일 해시도 배포 파일과 일치했다. [배포 기록](public-distribution.json).
